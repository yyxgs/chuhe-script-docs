# AI 生成注意事项

## 1. 不要根据功能名称猜测命令名称

例如教程文件名叫：

```text
极简输入弹窗.txt
```

不能因此直接假设命令一定叫：

```text
极简输入弹窗()
```

功能名称和实际命令名称不是同一个概念。

## 2. 不要自行增加参数

如果官方资料没有确认某个命令的参数，AI 不应根据其他自动化语言推测。

## 3. 输入与键盘按键不是同一类操作

`输入`、`输入字母` 等输入命令与 `按下`、`弹起`、`按键` 等键盘控制命令应分别处理。

## 4. 使用英文括号和逗号

楚河脚本代码使用英文：

```text
输入("hello")
```

不要使用中文括号或中文逗号。

## 5. 教程说明不是语法定义

教程中的说明文字、示意文字和示例注释不能直接当成楚河脚本语法。
