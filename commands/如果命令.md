# 楚河脚本如果命令

本文档记录楚河脚本中已经确认的条件判断语法。

---

## 1. 如果

### 命令介绍

`如果` 是楚河脚本的逻辑判断语法。

用于判断条件是否成立：

* 条件成立时，执行 `如果` 与 `否则` 之间的代码。
* 条件不成立时，执行 `否则` 与 `如果完成` 之间的代码。

### 基本结构

```text
如果 条件
	条件成立时执行的代码
否则
	条件不成立时执行的代码
如果完成
```

### 重要规则

一个完整的 `如果` 语句必须由以下三部分组成：

```text
如果
否则
如果完成
```

**三者缺一不可。**

即使条件不成立时没有实际需要执行的操作，也不能省略 `否则`。

### 支持的条件形式

条件判断使用楚河脚本已经定义的比较关系，例如：

```text
等于
小于
大于
不等于
小于等于
大于等于
```

### 示例

判断 `a` 是否等于 `3`：

```text
a = 2
a = a + 1

如果 a 等于 3
	显示("a现在是3，我去打开计算器")
	打开文件("c:/windows/system32/calc.exe")
	等待(1000)
否则
	显示("a不是等于3的")
如果完成
```

---

## 2. 否则

### 命令介绍

`否则` 用于指定条件不成立时执行的代码。

`否则` 不能脱离完整的 `如果` 结构单独使用。

### 基本结构

```text
如果 条件
	条件成立时执行的代码
否则
	条件不成立时执行的代码
如果完成
```

### 示例

根据 `b` 的值改变 `a`：

```text
a = 0
b = 50

如果 b 小于 100
	a = 8888
	显示(a)
	等待(1000)
	显示("请把b的值改为150，保存后再次运行")
否则
	a = 9999
	显示(a)
	等待(1000)
	显示("由于这次b不小于100，所以a是9999了")
如果完成
```

当 `b = 50` 时，`b 小于 100` 成立，因此执行 `a = 8888`。

如果 `b` 不小于 `100`，则执行 `否则` 中的代码。

---

## 3. 如果完成

### 命令介绍

`如果完成` 表示一个 `如果` 条件判断结构的结束。

### 基本结构

```text
如果 条件
	条件成立时执行的代码
否则
	条件不成立时执行的代码
如果完成
```

`如果完成` 必须与前面的 `如果` 和 `否则` 配套使用。

---

# 嵌套如果

楚河脚本允许在 `如果` 内部继续使用 `如果`。

例如判断鼠标是否位于屏幕左上角：

```text
横轴坐标 = 0
纵轴坐标 = 0

循环 0 小于 1
	鼠标位置 = 获取鼠标位置()
	横轴坐标 = x(鼠标位置)
	纵轴坐标 = y(鼠标位置)

	如果 横轴坐标 等于 0
		如果 纵轴坐标 等于 0
			打开文件("c:/windows/system32/calc.exe")
			跳出循环
		否则
			显示(鼠标位置)
		如果完成
	否则
		显示(鼠标位置)
	如果完成
循环完成
```

这里存在两层 `如果`：

```text
如果 横轴坐标 等于 0
	如果 纵轴坐标 等于 0
		...
	否则
		...
	如果完成
否则
	...
如果完成
```

第一层判断 X 坐标是否为 `0`。

如果成立，再进入第二层判断 Y 坐标是否为 `0`。

只有 X 和 Y 都为 `0` 时，才执行打开计算器的操作。

# 在循环中使用如果

`如果` 可以放在循环内部，根据循环过程中变量的当前值执行不同操作。

### 示例

```text
a = 0

循环 a 小于 999
	如果 a 等于 2
		显示("现在是2，马上就要到31了")
		等待(1000)
	否则
		
	如果完成

	如果 a 等于 3
		显示("现在是3了，可以打开计算器了")
		打开文件("c:/windows/system32/calc.exe")
		等待(1000)
	否则
		显示(a)
		等待(1000)
	如果完成

	a = a + 1
循环完成
```

# AI 生成注意事项

## 1. `否则` 不能省略

错误：

```text
如果 a 等于 3
	显示("a是3")
如果完成
```

正确：

```text
如果 a 等于 3
	显示("a是3")
否则
如果完成
```

如果不需要执行任何 `否则` 操作，也必须保留 `否则`。

## 2. `如果完成` 不能省略

每个 `如果` 都必须有对应的 `如果完成`。

## 3. 嵌套 `如果` 必须正确对应

嵌套条件判断时，每个 `如果` 都必须对应自己的：

```text
否则
如果完成
```

不能因为是嵌套结构就省略。

## 4. 条件与代码分开

`如果` 后面写判断条件，条件成立或不成立时执行的代码放在下一行，并按照楚河脚本的缩进规则进行缩进。

例如：

```text
如果 a 等于 3
	显示("a是3")
否则
	显示("a不是3")
如果完成
```

## 5. 不要使用其他语言的条件语法

不要把其他编程语言中的：

```text
if
else
}
```

等语法套用到楚河脚本。

楚河脚本使用：

```text
如果
否则
如果完成
```

构成完整的条件判断结构。

## 6. 不要自行创造 `否则如果`

楚河脚本条件判断应按照已经确认的语法编写。

不要因为其他语言存在 `else if`，就自行创造：

```text
否则如果
```

## 7. 注意条件中的命令调用限制

楚河脚本语言规则规定，不能在 `如果` 条件所在的同一行直接放置函数调用。

应该先得到结果，再进行判断。

例如：

```text
鼠标位置 = 获取鼠标位置()
横轴坐标 = x(鼠标位置)
纵轴坐标 = y(鼠标位置)

如果 横轴坐标 等于 0
	...
否则
	...
如果完成
```

而不是自行把函数调用嵌入条件表达式。

## 8. 使用已经确认的比较关系

目前已确认的比较关系包括：

```text
等于
小于
大于
不等于
小于等于
大于等于
```

不要使用其他编程语言的：

```text
==
<
>
!=
<=
>=
```

来代替楚河脚本的条件语法。
