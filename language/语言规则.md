# 楚河脚本语言规则

## 1. 语言基本规则

编程语言名称：**楚河**

楚河脚本是一种独立的脚本语言，不应按照 Java、Python、JavaScript 等其他编程语言的语法进行推测。

### 1.1 一行只能写一条语句

每一行只能写一条楚河脚本语句。

### 1.2 不支持嵌套函数调用

不支持在一个函数调用的参数中继续调用另一个函数。

错误示例：

```text
函数名(函数名(参数1, 参数2))
```

应该先将内部结果保存到变量，再进行下一步操作。

---

# 2. 变量

## 2.1 变量必须先定义或初始化

变量必须定义或者初始化以后才能使用。

例如：

```text
i = 0
```

这同时完成变量的定义和赋值。

## 2.2 变量赋值

支持：

```text
str = ""
i = 0
i = i + 1
```

不支持：

```text
i++
```

不支持直接使用字符串加法进行字符串拼接：

```text
str3 = str1 + str2
```

字符串拼接应使用楚河脚本提供的字符串拼接命令。

## 2.3 默认基本类型

楚河脚本变量默认的基本类型为字符串。

例如：

```text
i = 0
str = 拼接字符串("你好", i)
```

这里的 `i` 可以直接作为参数使用，不需要先转换成字符串。

如果需要从字符串进行数字计算，建议先转换为整数：

```text
numberStr = "33"
number = 转换为整数(numberStr)
i = 5 + number
println("i的值是：", i)
```

---

# 3. 循环

## 3.1 基本语法

楚河脚本循环使用：

```text
循环 条件
    // 循环内容
循环完成
```

循环条件只支持整数之间的比较。

## 3.2 无限循环

例如：

```text
循环 0 小于 1
    // 中间放要循环的语句
循环完成
```

## 3.3 整数循环

例如：

```text
i = 0
循环 i 小于 9
    // 中间放要循环的语句
    i = i + 1
循环完成
```

## 3.4 循环条件限制

循环条件的比较双方都必须是整数。

只支持：

```text
循环 整数 小于 整数
循环 整数 大于 整数
```

以及楚河脚本支持的其他整数比较关系。

不支持使用字符串作为循环条件比较对象。

不支持在循环条件所在的同一行调用函数。

例如，不应写成：

```text
循环 获取数组长度(list) 大于 0
```

应先将函数结果保存到变量：

```text
listLength = 获取数组长度(list)
循环 listLength 大于 0
    // 循环内容
循环完成
```

函数调用可以出现在循环块内部。

## 3.5 继续循环和跳出循环

```text
继续循环
```

等同于其他编程语言中的 `continue`。

```text
跳出循环
```

等同于其他编程语言中的 `break`。

---

# 4. 条件判断

## 4.1 支持的比较关系

楚河脚本支持：

* 等于
* 小于
* 大于
* 不等于
* 小于等于
* 大于等于

同时支持：

* `或者`：相当于 `||`
* `并且`：相当于 `&&`

## 4.2 基本语法

```text
如果 条件
    // 条件成立时执行
否则
    // 条件不成立时执行
如果完成
```

## 4.3 `否则` 必须存在

楚河脚本的 `如果` 结构必须完整使用：

```text
如果
否则
如果完成
```

即使实际上没有需要执行的“否则”代码，也必须保留 `否则`。

不能因为没有否则逻辑而省略 `否则`。

## 4.4 条件判断对象

`如果` 语句可以判断：

* 字符串
* 整数
* `是`
* `否`

字符串只支持：

* 等于
* 不等于

## 4.5 字符串是否为空

建议使用对比字符串命令判断字符串是否为空，而不是直接依赖其他判断方式。

例如：

```text
cmpResult = 对比字符串(result, "")
如果 cmpResult 等于 是
    println("空字符串")
否则
    // 非空字符串
如果完成
```

## 4.6 条件同行不能调用函数

条件所在的同一行不支持函数调用。

错误示例：

```text
如果 获取字符串长度(str) 大于 0
```

应先保存函数返回值：

```text
length = 获取字符串长度(str)
如果 length 大于 0
    // 条件成立
否则
    // 条件不成立
如果完成
```

函数调用可以出现在 `如果` 块内部。

## 4.7 不支持多个逻辑判断组合

一条语句中不支持多个 `与`、`或`、`非` 等逻辑判断进行复杂嵌套组合。

生成楚河脚本时，应按照官方支持的逻辑表达方式编写。

## 4.8 不支持 `否则如果`

不支持：

```text
如果
否则如果
否则
如果完成
```

也就是说，不支持 `如果-否则如果-否则-如果完成` 这种语法结构。

需要多个条件时，应使用楚河脚本支持的其他方式重新组织逻辑。

---

# 5. 缩进

`如果` 和 `循环` 等代码块内部的下一层语句必须使用 **Tab（`\t`）** 缩进。

**不能使用空格代替 Tab。**

例如：

```text
如果 i 小于 3
	显示("小于3")
否则
	显示("大于等于3")
如果完成
```

这里的缩进必须是真正的 Tab 字符。

---

# 6. 函数调用

## 6.1 一行只能写一条语句

函数调用必须独立占用一条语句。

## 6.2 不支持多重嵌套括号

不支持：

```text
函数名(函数名(参数1, 参数2))
```

应先保存内部结果：

```text
result = 函数名(参数1, 参数2)
result2 = 其他函数(result)
```

## 6.3 参数分隔符

函数参数必须使用英文逗号 `,` 分隔。

例如：

```text
拼接字符串("hello", "world")
```

---

# 7. 数组

## 7.1 数组元素赋值

支持：

```text
list[0] = ""
list[1] = ""
```

也可以将命令返回的数组赋值给变量：

```text
list = 读取文本(txtPath)
```

## 7.2 不支持空数组定义

不支持：

```text
list[] = {"", ""}
```

楚河脚本不支持使用这种方式定义数组。

## 7.3 数组元素赋值

支持：

```text
list2[0] = list[0]
list2[1] = list[1]
list2[2] = "hello"
```

## 7.4 数组下标表达式限制

不支持直接使用复杂表达式作为数组下标。

例如不支持：

```text
arr[i + 1] = 3
```

应先计算下标：

```text
i2 = i + 1
arr[i2] = 3
```

---

# 8. 注释

## 8.1 单行注释

支持使用 `//` 进行单行注释。

例如：

```text
// 这是注释
println("hello")
```

## 8.2 块注释

支持：

```text
/*
这是块注释
*/
```

但是 `/*` 和 `*/` 必须各自单独占一行。

## 8.3 语句末尾不能添加注释

绝对不能在楚河脚本语句的同一行末尾添加注释。

错误：

```text
读取文本(path) // 错误
```

错误：

```text
读取文本(path) /* 错误
```

## 8.4 注释格式建议

为了保持代码可读性，建议注释块上下各保留一个空行。

对于普通注释，也建议在注释前保留适当的空行，使代码结构更加清晰。

---

# 9. 转义字符

楚河脚本支持以下转义字符：

```text
\"
\n
\r
\t
\\
```

文本绝对路径推荐使用 `/`：

```text
c:/下载/1.txt
```

除非某些命令的路径拼接确实需要使用 `\`，否则推荐使用 `/`。

---

# 10. 模块（函数）

楚河脚本中的模块可以理解为可复用的函数代码。

## 10.1 在当前脚本底部定义模块

支持直接在脚本文件底部定义：

```text
做个模块 模块名()
	// 代码
模块完成
```

## 10.2 在独立文件中定义模块

推荐将模块放在独立的文本文件中。

例如 `模块1.txt`：

```text
做个模块 模块名(参数1, 参数2)
	// 代码
	模块名 = 返回值
模块完成
```

然后使用：

```text
安装模块("c:/楚河脚本/模块目录/模块1.txt")
```

即可使用其中定义的模块。

## 10.3 模块返回值

模块一般用于返回一个值，也可以返回数组。

## 10.4 模块参数

模块支持传递：

* 普通变量
* `LortImage` 的 `lg` 对象
* `bi` 对象
* 数组

传递数组时，需要在调用参数中使用数组名和 `[]`：

```text
dolist(list[])
```

例如：

```text
list[0] = "hello"
list[1] = "world"

dolist(list[])
```

模块：

```text
做个模块 dolist(list)
	i = 0
	listLength = 获取数组长度(list)
	循环 i 小于 listLength
		println(list[i], " ")
		i = i + 1
	循环完成
	println()
模块完成
```

# 11. 运行其他脚本文件

## 11.1 基本用法

可以在当前脚本中运行另一个脚本文件。

语法：

```text
运行一个脚本文件(脚本绝对路径)
```

被调用的脚本与当前脚本的变量相互隔离。

## 11.2 传递参数和返回值

例如 `01.txt`：

```text
a = 100
b = 50

println("调用02")
result = 运行一个脚本文件("c:/楚河脚本/脚本目录/02.txt", a, b)
println("返回值：", result)
```

`02.txt`：

```text
println("收到参数1：", __param1__, "，参数2：", __param2__)

sum = __param1__ + __param2__

println("计算结果：", sum)

__return__ = sum
```

调用脚本可以通过参数将值传递给被调用脚本，被调用脚本通过 `__return__` 返回结果。

# 12. 脚本之间共享变量

早期可以通过临时文本文件进行脚本之间的数据中转。

相关历史命令包括：

* 读取资源目录临时文本变量
* 写入资源目录临时文本变量
* 读取资源目录临时文本数字
* 写入资源目录临时文本数字

后来增加了全局变量机制。

相关命令包括：

* 设置全局变量
* 获取全局变量
* 清空全局变量
* 删除全局变量

这些全局变量命令用于在脚本之间通过内存共享单个值。

**注意：这些全局变量命令不支持数组，只支持单个值。**

# 13. 运行脚本并拷贝变量

如果需要将父脚本中的变量传递给子脚本，可以使用：

```text
运行一个脚本文件并拷贝变量(脚本绝对路径)
```

该命令会将当前脚本的变量进行深拷贝，并传递给子脚本。

子脚本可以直接使用父脚本传入的变量。

子脚本对这些变量进行修改时，不会影响父脚本中的原变量。

变量传递方向是单向的：

```text
父脚本 → 子脚本
```

不会自动从子脚本返回变量修改结果。

## 13.1 示例

父脚本 `01.txt`：

```text
a = 3
b = 4

list[0] = 1
list[1] = 2
list[2] = "python"

运行一个脚本文件并拷贝变量("c:/楚河脚本/脚本目录/02.txt")

println("01里面的代码a的值是: ", a, "，b的值是: ", b)
```

子脚本 `02.txt`：

```text
println("我是02")
println("a的值是: ", a, "，b的值是: ", b)

a = 0
b = 1

println("02修改后a的值是: ", a, "，b的值是: ", b)
```

子脚本可以直接读取父脚本传入的变量，但修改后的 `a`、`b` 不会影响父脚本。

# 14. AI 生成代码时必须特别注意

生成楚河脚本时，应重点检查以下常见错误：

1. 在 `如果` 条件同行调用函数。
2. 在 `循环` 条件同行调用函数。
3. 使用 `i++`。
4. 使用其他编程语言的变量或表达式语法。
5. 使用嵌套函数调用。
6. 使用字符串加法代替楚河脚本的字符串拼接命令。
7. 使用字符串作为循环条件比较对象。
8. 直接写 `arr[i + 1]` 这样的数组下标表达式。
9. 省略 `否则`。
10. 使用 `否则如果`。
11. 使用空格而不是 Tab 进行代码块缩进。
12. 在语句行末尾添加 `//` 或 `/* */` 注释。
13. 自行创造官方文档中不存在的命令。

如果无法从官方文档确认某个命令或语法，应先查阅对应官方命令文档，而不是根据其他编程语言进行推测。
