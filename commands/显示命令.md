# 楚河脚本显示命令

本文档记录楚河脚本中已经确认的显示相关命令。

---

## 1. 显示

### 命令介绍

在编辑器左下角固定位置显示当前的一条提示文字。

新的文字出现后会直接覆盖旧文字，而不是不断追加形成日志。

### 语法

```text
显示(内容)
```

### 参数

* `内容`：要显示的内容。
* 可以同时传入多个内容，使用英文逗号 `,` 分隔。

### 示例

显示一条文字：

```text
显示("你好")
```

同时显示多个内容：

```text
显示("这个坐标的x是", x, ", y是", y)
```

---

## 2. 倒计时显示

### 命令介绍

在脚本的左下角倒计时显示指定的内容。

### 语法

```text
倒计时显示(内容, 秒数, 单位文字)
```

### 参数

* `内容`：倒计时前显示的提示内容。
* `秒数`：倒计时的秒数。
* `单位文字`：倒计时显示的单位文字。

### 示例

```text
倒计时显示("休息时间还剩...", 3, "秒")
```

---

## 3. 弹窗提示

### 命令介绍

在屏幕上弹出一个窗口提示一句简短的话。

### 语法

```text
弹窗提示(内容, x, y)
```

### 参数

* `内容`：弹窗显示的文字。
* `x`：弹窗位置的 X 坐标。
* `y`：弹窗位置的 Y 坐标。

### 示例

```text
弹窗提示("Hello1", 100, 100)
```

```text
弹窗提示("你的好友发来了一条消息", 1510, 830)
```

---

## 4. print

### 命令介绍

在控制台窗口显示内容。

多个内容使用英文逗号 `,` 分隔。

### 语法

```text
print(内容)
```

也可以同时传入多个内容：

```text
print(内容1, 内容2, ...)
```

### 示例

```text
tempStr = "水果"
print("你好", tempStr)
```

---

## 5. println

### 命令介绍

在控制台窗口显示内容。

多个内容使用英文逗号 `,` 分隔。

### 语法

```text
println(内容)
```

也可以同时传入多个内容：

```text
println(内容1, 内容2, ...)
```

### 示例

```text
println("你好")
println("你好", tempStr)
i = 0
println("第", i, "次")
```

# AI 生成注意事项

## 1. 显示可以传入多个内容

例如：

```text
显示("这个坐标的x是", x, ", y是", y)
```

不要因为其他编程语言通常需要字符串拼接，就自行改写成其他语法。

## 2. 倒计时显示不是等待命令

已确认的使用形式：

```text
倒计时显示("休息时间还剩...", 3, "秒")
```

不要自行改成：

```text
倒计时显示(3000)
```

除非官方资料明确确认这种参数形式。

## 3. 弹窗提示需要位置参数

已确认的使用形式：

```text
弹窗提示("Hello1", 100, 100)
```

其中后两个参数用于指定弹窗位置。

## 4. print 和 println 可以传入多个内容

例如：

```text
print("你好", tempStr)
println("第", i, "次")
```

多个内容之间使用英文逗号 `,`。

## 5. 使用英文逗号

正确：

```text
显示("x是", x)
```

错误：

```text
显示("x是"，x)
```

## 6. 不要把教程说明文字当成代码

教程中的说明文字不代表楚河脚本支持行尾注释。

## 7. 未确认的参数不要自行添加

如果官方资料没有明确确认某个命令支持其他参数形式，AI 不应自行增加参数形式。
