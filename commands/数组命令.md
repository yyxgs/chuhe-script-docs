# 楚河脚本数组命令

本文档记录楚河脚本中已经确认的数组相关语法和命令。

---

## 1. 数组

### 命令介绍

数组就是一组变量的集合。

普通变量可以分别保存多个值：

```text
number1 = 777
number2 = 888
number3 = 999
```

使用数组可以将这些值放在同一个数组中：

```text
list[0] = 777
list[1] = 888
list[2] = 999
```

数组使用索引访问元素，索引从 `0` 开始。

### 基本语法

```text
数组名[索引] = 值
```

### 示例

```text
list[0] = 777
list[1] = 888
list[2] = 999

length = 获取数组长度(list)
显示("这个数组一共有", length, "个元素")
```

## 2. 获取数组长度

### 命令介绍

获取数组中元素的数量。

### 语法

```text
获取数组长度(数组名)
```

### 参数

* `数组名`：要获取长度的数组。

### 返回值

返回数组中元素的数量。

### 示例

```text
list[0] = 777
list[1] = 888
list[2] = 999

length = 获取数组长度(list)
显示("这个数组一共有", length, "个元素")
```

## 3. 清空数组元素

### 命令介绍

清空数组里的所有元素，使其变成一个空数组。

### 语法

```text
清空数组元素(数组名1, ...)
```

可以同时清空多个数组。

### 参数

* `数组名1`：要清空的数组。
* 可以同时传入多个数组名称。

### 使用场景

当 `index` 和 `color` 数组用于储存多点比色的坐标和颜色时，如果前一次使用的数组元素数量更多，而下一次使用的元素数量更少，之前残留的数组元素可能继续存在。

例如：

第一次使用了 5 组坐标和颜色，之后只准备使用 4 组。如果没有清空数组，之前的第 5 组数据可能仍然存在。

这种情况下，可以在两次使用之间执行：

```text
清空数组元素(index, color)
```

### 示例

第一次保存 3 组数据：

```text
index[0] = "379, 186"
color[0] = "94B8D2"

index[1] = "529, 266"
color[1] = "A0C0D7"

index[2] = "691, 188"
color[2] = "A2C2D9"

indexLength = 获取数组长度(index)
colorLength = 获取数组长度(color)

显示("indexLength的值是: ", indexLength, "，colorLength的值是: ", colorLength)
等待(1000)
```

清空两个数组：

```text
清空数组元素(index, color)
```

重新保存数据：

```text
index[0] = "404, 188"
color[0] = "95B9D3"

index[1] = "609, 142"
color[1] = "9BBDD6"

indexLength = 获取数组长度(index)
colorLength = 获取数组长度(color)

显示("indexLength的值是: ", indexLength, "，colorLength的值是: ", colorLength)
```

## 4. 数组转大文本数组

### 命令介绍

将普通数组转换为大文本数组。

### 语法

```text
数组转大文本数组(普通数组名, "大文本数组名")
```

### 参数

* `普通数组名`：需要转换的普通数组。
* `"大文本数组名"`：转换后使用的大文本数组名称。

### 注意

如果指定的大文本数组已经存在，会直接覆盖。

### 示例

读取文本后转换为大文本数组：

```text
path = "c:/下载/5.txt"
list = 读取文本(path)

数组转大文本数组(list, "list")

listLength = 获取大文本长度("list")

i = 0
循环 i 小于 listLength
	str = 大文本中获取行("list", i)
	println("第", i, "行的内容是: ", str)
	i = i + 1
循环完成
```

# AI 生成注意事项

## 1. 数组使用索引访问

正确：

```text
list[0] = 777
list[1] = 888
```

数组元素通过：

```text
数组名[索引]
```

访问。

## 2. 数组索引从 0 开始

例如：

```text
list[0]
list[1]
list[2]
```

分别表示第 1、2、3 个元素。

## 3. 获取数组长度使用数组名称

正确：

```text
length = 获取数组长度(list)
```

不要把数组元素写成：

```text
获取数组长度(list[0])
```

## 4. 清空数组可以同时处理多个数组

已经确认：

```text
清空数组元素(index, color)
```

## 5. 注意数组数据残留

如果同一个脚本中重复使用数组，特别是 `index`、`color` 等用于图色数据的数组，在重新写入数量更少的数据之前，应根据实际需求使用：

```text
清空数组元素(index, color)
```

避免旧元素继续保留。
