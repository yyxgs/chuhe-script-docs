# 楚河脚本鼠标键盘示例

本文档用于展示楚河脚本中鼠标和键盘命令的常见组合方式。

示例中的命令均应以：

* `commands/鼠标命令.md`
* `commands/键盘命令.md`
* `language/语言规则.md`

中的正式定义为准。

---

# 1. 鼠标移动

将鼠标移动到指定坐标：

```text
鼠标移动(500, 300)
```

移动后等待：

```text
鼠标移动(500, 300)
等待(500)
```

---

# 2. 鼠标左键点击

移动到指定位置后点击：

```text
鼠标左键点击(500, 300)
```

连续点击不同位置：

```text
鼠标左键点击(500, 300)
等待(200)

鼠标左键点击(700, 400)
等待(200)

鼠标左键点击(900, 500)
```

---

# 3. 鼠标右键点击


例如右键点击后等待：

```text
鼠标右键点击(500, 300)

```

# 4. 鼠标双击

# 5. 鼠标按下与弹起

如果需要让鼠标左键保持按下状态，应分别使用按下和弹起命令：

```text
鼠标左键按下()

等待(2000)

鼠标左键弹起()
```

例如配合鼠标移动：

```text
鼠标移动(500, 300)

鼠标左键按下()

等待(500)

鼠标移动(800, 300)

鼠标左键弹起()
```

---

# 6. 鼠标拖动

使用鼠标左键按下、移动、弹起，可以实现持续按住状态下的拖动：

```text
鼠标移动(500, 300)

鼠标左键按下()

等待(200)

鼠标移动(800, 500)

等待(200)

鼠标左键弹起()
```

# 23. 根据条件决定是否点击

鼠标操作可以与 `如果` 结合。

```text
i = 0

循环 i 小于 10

	如果 i 等于 5
		鼠标左键点击(500, 300)
	否则
		println("当前不点击")
	如果完成

	i = i + 1

循环完成
```

# 26. 鼠标监听

开启鼠标监听线程：

```text
开启鼠标监听线程()
```

然后获取监听键值：

```text
result = 获取鼠标监听键值()

```

`开启鼠标监听线程()` 在一次软件运行过程中只需要按照实际使用需求开启，不应重复创建不必要的监听线程。

# AI 使用注意事项

1. 鼠标和键盘命令必须使用楚河脚本官方命令名称。
2. 不要使用 Python、JavaScript、AutoHotkey 等其他语言的鼠标键盘语法代替楚河脚本语法。
3. 需要持续按住鼠标时，应使用“按下”和“弹起”两个命令配合。
4. 需要持续按住键盘按键时，同样需要正确执行按下和弹起。
5. 鼠标拖动通常需要保持鼠标左键处于按下状态，再移动鼠标，最后弹起鼠标左键。
6. 循环中的计数变量必须先初始化。
7. 楚河脚本不使用 `i++`。
8. `如果` 必须使用完整的 `如果 / 否则 / 如果完成` 结构。
9. 不要使用 `否则如果`。
10. 命令之间需要按照实际执行顺序编写，涉及点击、输入、窗口响应时通常需要根据实际情况加入 `等待()`。
11. `human` 系列命令与普通鼠标命令是不同的命令形式，应使用其已经确认的参数。
12. 后台鼠标操作涉及窗口句柄，应以官方鼠标命令文档中的定义为准。
13. 示例只展示代码结构，不代表所有坐标都适用于所有电脑或软件界面。
