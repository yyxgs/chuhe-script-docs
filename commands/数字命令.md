## 1. 获取随机数

### 命令介绍

获取指定范围内的随机数。

### 语法

```text
获取随机数(最小值, 最大值)
```

### 参数

* `最小值`：随机数范围的最小值。
* `最大值`：随机数范围的最大值。

### 示例

获取一个 `100` 到 `200` 之间的随机数：

```text
随机数 = 获取随机数(100, 200)
显示(随机数)
```

### 实际应用：随机等待时间

例如需要随机等待 `10` 到 `20` 秒：

```text
number = 获取随机数(10, 20)

倒计时显示("等待时间还剩...", number, "秒")
```

### 实际应用：循环获取随机数

```text
i = 0
循环 i 小于 10
	随机数 = 获取随机数(100, 200)
	显示(随机数)
	等待(1000)

	i = i + 1
循环完成
```

## 2. 获取数字到字母

### 命令介绍

根据数字索引获取对应的字符。

教程示例用于依次获取：

```text
0 - 9
a - z
A - Z
```

### 语法

```text
获取数字到字母(数字)
```

### 示例

依次获取 `0-9、a-z、A-Z`：

```text
i = 0
循环 i 小于 62
	str = 获取数字到字母(i)
	显示(str)
	等待(100)

	i = i + 1
循环完成
```

### 注意事项

教程明确使用 `0` 到 `61`，共 `62` 个索引。

## 3. 判断是否为数字字符串

### 命令介绍

判断一个字符串是否为数字字符串。

### 语法

```text
判断是否为数字字符串(字符串)
判断是否为数字字符串(字符串, 允许小数点)
```

### 参数

* `字符串`：需要判断的字符串。
* `允许小数点`：是否允许字符串包含小数点。

### 返回值

返回：

```text
是
```

或者：

```text
否
```

### 示例：不允许小数点

```text
r = 判断是否为数字字符串("392392")
如果 r 等于 是
	显示("是数字字符串，绝对没小数点")
	等待(1000)
否则
	显示("不是数字字符串")
	等待(1000)
如果完成
```

### 示例：允许小数点

第二个参数设置为 `1`：

```text
r = 判断是否为数字字符串("158.88", 1)
如果 r 等于 是
	显示("是数字字符串，可能包含小数点")
	等待(1000)
否则
	显示("不是数字字符串")
	等待(1000)
如果完成
```
