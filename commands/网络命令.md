# 楚河脚本网络命令

本文档记录已经确认的楚河脚本网络相关命令。

这些命令主要用于：

* 文件下载
* HTTP 网页获取
* OCR 文字识别
* Umi-OCR 识别
* AI 问答
* 图像验证码识别
* 文件与文件夹服务器传输
* 淘宝 JSON 数据解析
* 消息通知

---

## 1. 下载

### 命令介绍

下载一个文件。

### 语法

```text
下载(下载地址, 保存路径)
```

### 参数

* `下载地址`：文件下载地址。
* `保存路径`：下载后保存的目录和文件名。

### 示例

```text
显示("开始下载...")

下载("https://down.qq.com/qqweb/PCQQ/PCQQ_EXE/PCQQ2021.exe", "d:/qq.exe")

显示("下载成功")
```

## 2. 线程下载

### 命令介绍

开启一个线程循环下载一个文件，直到下载成功才会停止这个线程。

### 语法

```text
线程下载(下载地址, 保存路径)
```

### 参数

* `下载地址`：文件下载地址。
* `保存路径`：下载后保存的目录和文件名。

### 示例

```text
显示("第1个下载线程已开启...")
等待(1000)

线程下载("https://down.qq.com/qqweb/PCQQ/PCQQ_EXE/PCQQ2021.exe", "C:\\BaiduDiskDownload\\第1个QQ.exe")

显示("第2个下载线程已开启...")
等待(1000)

线程下载("https://down.qq.com/qqweb/PCQQ/PCQQ_EXE/PCQQ2021.exe", "C:\\BaiduDiskDownload\\第2个QQ.exe")

显示("两个线程下载已创建完成，请等待它们下载成功")
```

## 4. 百度OCR识别

### 命令介绍

使用百度 OCR 进行通用文字识别。

### 语法

```text
百度OCR识别(图片路径, AK, SK)
```

### 参数

* `图片路径`：需要识别的图片路径。
* `AK`：百度提供的 Access Key。
* `SK`：百度提供的 Secret Key。

### 示例

```text
path = "c:/楚河脚本/资源目录/截图.png"

result = 百度OCR识别(path, "*", "*")

显示(result)

startStr = "\"words\":\""
endStr = "\"}]"

startPos = 查找字符串位置(result, startStr, 0)
endPos = 查找字符串位置(result, endStr, 0)
startPosLen = 获取字符串长度(startStr)

resultStr = 字符串里拷贝字符串(result, startPos, endPos, startPosLen, 0)

显示(resultStr)
```

`*` 仅作为示例占位符，实际使用时需要填写百度提供的 AK 和 SK。

### 图片文字类型

* `1`：纯数字
* `1001`：纯数字2
* `2`：纯英文
* `1002`：纯英文2
* `3`：数英混合
* `1003`：数英混合2
* `4`：闪动GIF
* `7`：无感学习
* `11`：计算题
* `1005`：快速计算题
* `16`：汉字
* `32`：通用文字识别
* `66`：问答题
* `49`：reCAPTCHA 图片识别

### 图片旋转角度类型

* `29`：旋转类型

### 图片坐标点选类型

* `19`：1个坐标
* `20`：3个坐标
* `21`：3～5个坐标
* `22`：5～8个坐标
* `27`：1～4个坐标
* `48`：轨迹类型

### 缺口识别

* `18`：缺口识别

### 拼图识别

* `53`：拼图识别

### 示例

```text
    tempStr = list[i]

    xStr = 拷贝方向字符串(tempStr, ",", 1, 0)
    yStr = 拷贝方向字符串(tempStr, ",", 2, 0)
```

## 11. umi是否在运行

### 命令介绍

支持三种使用方式：

```text
umi是否在运行()
```

* 不传参数：只检测是否运行。

* 传入路径：检测是否运行，并根据指定路径尝试启动。

### 示例

```text

否则
    显示("在运行")

```


```text
读取屏幕到bi("bi", 0, 0, 1920, 1080)

content = umi识别bi("1224", "bi", 290, 420, 696, 445)
```

## 22. umi查找多行多位置中心坐标bi

### 命令介绍

查找指定文字的所有匹配位置，并返回所有匹配位置的中心坐标数组。

如果没有找到任何匹配，返回空数组。

### 格式1

```text
umi查找多行多位置中心坐标bi("端口", 左X, 左Y, 右X, 右Y, "查找内容")
```

### 格式2

```text
umi查找多行多位置中心坐标bi("端口", "bi名", 左X, 左Y, 右X, 右Y, "查找内容")
```

格式2需要事先调用 `读取屏幕到bi`。

### 坐标注意事项

返回的坐标是**相对于截图区域左上角的坐标**。

如果需要转换成屏幕真实坐标，需要加上截图区域的 `左X` 和 `左Y`。

### 示例

```text
findContent = "合格"

resultList = umi查找多行多位置中心坐标bi("1224", 913, 366, 1045, 853, findContent)

数量 = 获取数组长度(resultList)

显示("找到的数量是: ", 数量)

i = 0

循环 i 小于 数量
    当前坐标 = resultList[i]

    坐标x = x(当前坐标)
    坐标y = y(当前坐标)

    坐标x = 坐标x + 913
    坐标y = 坐标y + 366

    结果坐标 = xy(坐标x, 坐标y)

    println("第", i, "个坐标是: ", 坐标x, ", ", 坐标y)

    扩散坐标范围(结果坐标, -41, -19, 42, 20, leftX, leftY, rightX, rightY)

    截图(leftX, leftY, rightX, rightY, "c:/楚河脚本/资源目录/临时截图.png")

    打开文件("c:/楚河脚本/资源目录/临时截图.png")

    等待(1000)

    i = i + 1
循环完成
```

# AI 注意事项

1. `下载` 与 `线程下载` 是不同命令，不要混淆。
2. `线程下载` 会开启线程循环下载，直到下载成功。
3. `百度OCR识别` 与 `百度OCR识别数字` 是不同命令。
4. Umi-OCR 相关命令需要根据具体命令确认是否使用图片路径或 `bi` 对象。
5. `umi识别bi`、`umi识别多行bi`、`umi查找多行中心坐标bi` 均支持直接截图区域和已有 `bi` 对象两种形式。
6. `umi查找多行多位置中心坐标bi` 返回的是相对于截图区域左上角的坐标，需要根据截图区域偏移量转换成屏幕坐标。
7. 图鉴识别和冰拓识别属于外部识别服务，需要对应账号或服务支持。
8. OCR、AI 问答等涉及外部服务的命令，其账号、密钥、端口等参数必须使用实际配置，不能由 AI 自行编造。
9. 教程中的 `*.*.*.*`、`0000`、`sk-*******`、`你的用户名` 等均为示例占位内容。
10. 第二个 `powershell` 类似的外部命令内容如果出现在其他教程中，应区分楚河脚本代码与外部程序原生命令，不要把外部命令直接当成楚河脚本语法。
11. 生成网络命令代码时，只能使用本文档中已经确认的命令和参数形式。
12. 如果某个网络功能没有在官方文档中确认具体语法，不得根据其他语言或其他软件的 API 自行推测。
