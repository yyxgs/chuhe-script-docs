# 楚河脚本显示命令

本文档记录楚河脚本中已经确认的显示相关命令。

---

## 1. 显示

### 语法

```text
显示(内容)
```

可以同时显示多个内容。

### 示例

```text
显示("你好")
```

同时显示多个内容：

```text
显示("x是", x, ", y是", y)
```

---

## 2. 倒计时显示

### 语法

```text
倒计时显示(毫秒数)
```

用于显示等待倒计时。

### 示例

```text
倒计时显示(5000)
```

---

## 3. 弹窗提示

### 语法

```text
弹窗提示(内容)
```

用于弹出提示窗口显示内容。

### 示例

```text
弹窗提示("操作完成")
```

---

## 4. print

### 语法

```text
print(内容)
```

用于输出内容。

### 示例

```text
print("hello")
```

---

## 5. println

### 语法

```text
println(内容)
```

用于输出内容。

### 示例

```text
println("hello")
```

---

# AI 生成注意事项

## 1. 显示多个内容

`显示` 可以一次传入多个内容，例如：

```text
显示("这个坐标的x是", x, ", y是", y)
```

不要因为其他语言通常需要字符串拼接，就自行改写成其他语法。

## 2. 使用英文逗号

正确：

```text
显示("x是", x)
```

不要使用中文逗号：

```text
显示("x是"，x)
```

## 3. 不要把教程说明文字当成代码

教程中的说明文字不代表楚河脚本支持行尾注释。

## 4. 未确认的参数不要自行添加

如果官方资料没有明确确认某个显示命令支持哪些参数，AI 不应自行增加参数形式。
