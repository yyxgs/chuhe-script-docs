# 楚河脚本：脚本文件命令

本文件记录楚河脚本中与脚本文件、模块、线程、JavaScript、全局变量以及脚本运行控制相关的命令。

---

## 1. 运行一个脚本文件

### 功能

在当前代码中指定运行另一个脚本文件。

默认编码格式为 UTF-8。

可以用于将大量代码拆分到多个脚本文件中，方便修改和排查问题。

### 语法

```text
运行一个脚本文件(路径)
```

也可以传入参数：

```text
运行一个脚本文件(路径, 参数1, 参数2, ...)
```

### 参数传递

被调用的脚本可以通过以下特殊变量接收参数：

```text
__param1__
__param2__
```

被调用脚本通过：

```text
__return__
```

返回结果。

### 示例

主脚本：

```text
a = 100
b = 50

println("调用02")
result = 运行一个脚本文件("c:/楚河脚本/脚本目录/02.txt", a, b)
println("返回值：", result)
```

02.txt：

```text
println("收到参数1：", __param1__, "，参数2：", __param2__)

sum = __param1__ + __param2__

println("计算结果：", sum)

__return__ = sum
```

### 返回多个变量

如果需要返回多个变量，可以将多个结果拼接成一个字符串，再由调用脚本分离。

主脚本：

```text
a = 100
b = 50

result = 运行一个脚本文件("c:/楚河脚本/脚本目录/02.txt", a, b)
println("返回值：", result)

sepStr = "|||"
resultList = 分离字符串(result, sepStr, 0)

i = 0
length = 获取数组长度(resultList)
循环 i 小于 length
	println("第", i, "个结果：", resultList[i])
	i = i + 1
循环完成
```

02.txt：

```text
sum = __param1__ + __param2__
diff = __param1__ - __param2__
product = __param1__ * __param2__
quotient = __param1__ / __param2__

result = 拼接字符串(sum, "|||", diff, "|||", product, "|||", quotient)

__return__ = result
```

## 2. 定时运行一个脚本文件

### 功能

定时运行指定的脚本文件。

到达指定时间后，相当于选择该脚本并点击运行。

默认编码格式为 UTF-8。

在指定时间到达之前，当前调用会一直等待。

### 语法

```text
定时运行一个脚本文件(指定运行时间, 脚本的路径)
```

也可以传入共享变量：

```text
定时运行一个脚本文件(指定运行时间, 脚本的路径, 共享变量1, ...)
```

### 时间格式

```text
年-月-日 时:分:秒.毫秒
```

### 示例

```text
定时运行一个脚本文件("2021-05-17 22:30:47.000", "c:/楚河脚本/脚本目录/打开计算器.txt")
```

传入共享变量：

```text
a = 0
b = 7
c = 10

定时运行一个脚本文件("2021-05-17 22:30:47.000", "c:/楚河脚本/脚本目录/打开计算器.txt", a, b, c)
```

## 3. 安装模块

### 功能

将其他脚本文件中的模块安装到当前脚本中，使当前脚本可以调用模块中的代码。

其他文件中的模块需要先安装。

当前文件中的模块不需要安装。

### 语法

```text
安装模块(模块文件路径)
```

### 模块定义

模块使用：

```text
做个模块 模块名(参数...)
	模块代码
模块完成
```

### 示例

模块文件：

```text
做个模块 fun1()
	输入("123456789")
	等待(1000)
模块完成

做个模块 fun2(list)
	length = 获取数组长度(list)
	显示(length)
	等待(1000)
模块完成
```

调用：

```text
安装模块("c:/楚河脚本/脚本目录/模块1.txt")

显示("开始使用其他脚本文件中的代码")

fun1()

list[0] = "苹果"
list[1] = "香蕉"

fun2(list[])
```

### 向模块传递 LortImage

```text
安装模块("c:/楚河脚本/脚本目录/模块1.txt")

str = "我是01里面的变量str"

读取屏幕到LortImage("lg", 0, 480, 200, 728)

println("楚河01开始调用模块里的识别...")

r = 识别1("lg", 143, 143, "F5125E")

println("r的值是: ", r)
```

模块中的代码：

```text
做个模块 识别1(lgName, x, y, colorStr)
	println("控制台显示楚河参数变量值里面：x的值是: ", x, "，y的值是: ", y, "，colorStr的值是: ", colorStr)

	result = 1

	hexColorStr = LortImageGetPixelColor(lgName, x, y)

	println("hexColorStr的值是: ", hexColorStr)

	r = 对比字符串(hexColorStr, colorStr)

	如果 r 等于 否
		result = 0
	否则
		result = 1
	如果完成

	识别1 = result
模块完成
```

## 4. 转换为模块代码并安装运行

### 功能

将一个识别代码文件转换为模块，并直接运行。

适合将坐标找色等识别代码制作成可重复调用的模块。

当需要重新制作识别时，只需要修改原来的识别代码文件。

### 语法

```text

```

### 示例

```text
result = 转换为模块代码并安装运行("c:/楚河脚本/脚本目录/坐标找色1.txt", "识别图标")

如果 result 等于 1
	显示("找到了")
	等待(1000)
否则
	显示("没找到")
	等待(1000)
如果完成
```

## 6. 中断脚本

### 功能

中断当前脚本文件的运行。

只会停止当前脚本文件，不会停止其他已经运行的脚本。

### 语法

```text
中断脚本()
```

### 示例

```text
输入("你好")
等待(1000)

中断脚本()

输入("吃饭了吗")
等待(1000)
```

如果当前脚本中又运行了其他脚本，被中断的只是当前脚本，不代表其他脚本也会停止。

---

## 7. 停止脚本

### 功能

使用代码代替脚本编辑器中的停止按钮，停止当前脚本运行。

### 语法

```text
停止脚本()
```

### 示例

```text
输入("你好")
等待(1000)

停止脚本()

输入("吃饭了吗")
等待(1000)
```

停止后，后面的代码不会继续运行。

---

## 8. 重头运行

### 功能

让当前脚本重新从头运行。

### 用法一

```text
重头运行()
```

直接回到当前脚本第 1 行开始运行。

### 用法二

```text
重头运行(-3, 1)
```

以当前行为位置向上倒退 3 行运行。

第 2 个参数为 `1` 时，会在控制台显示当前语句的内容和位置。

### 示例

```text
输入("你好")
等待(1000)

输入("吃饭了吗")
等待(1000)

重头运行()
```

运行到 `重头运行()` 后重新回到第 1 行，因此可以形成类似循环的效果。

# 线程命令

## 9. 创建线程

### 功能

创建一个线程，但不会立即开始执行线程脚本中的代码。

### 语法

```text
创建线程(线程名, 脚本路径)
```

创建线程后，线程单元已经存在并处于准备执行状态，因此会占用一定 CPU 资源。

### 示例

```text
path1 = "c:/楚河脚本/脚本目录/01.txt"
path2 = "c:/楚河脚本/脚本目录/02.txt"

tn1 = 创建线程("线程1", path1)
tn2 = 创建线程("线程2", path2)
```

---

## 10. 线程运行

### 功能

通过线程名开始运行已经创建的线程。

### 语法

```text
线程运行(线程名)
```

### 示例

```text
path1 = "c:/楚河脚本/脚本目录/01.txt"
path2 = "c:/楚河脚本/脚本目录/02.txt"

tn1 = 创建线程("线程1", path1)
tn2 = 创建线程("线程2", path2)

线程运行(tn1)
线程运行(tn2)
```

---

## 11. 线程停止

### 功能

通过线程名停止已经创建并正在运行的线程。

### 语法

```text
线程停止(线程名)
```

停止线程只代表停止运行，不代表释放线程单元。

只有销毁线程才会真正释放线程资源。

不建议强行停止线程，更适合让线程执行的脚本自行结束，例如在满足条件后跳出自身的无限循环。

### 示例

```text
path1 = "c:/楚河脚本/脚本目录/01.txt"
path2 = "c:/楚河脚本/脚本目录/02.txt"

tn1 = 创建线程("线程1", path1)
tn2 = 创建线程("线程2", path2)

线程运行(tn1)
线程运行(tn2)

i = 5
循环 0 小于 1
	println("主线程：还剩", i, "秒后停止线程2")
	等待(1000)
	i = i - 1

	如果 i 等于 0
		跳出循环
	否则
	如果完成
循环完成

线程停止(tn2)

println("线程2已停止！！！！！！！！")
等待(5000)

线程停止(tn1)
```

## 12. 线程销毁

### 功能

通过线程名销毁已经创建的线程，并释放线程占用的 CPU 资源。

### 语法

```text
线程销毁(线程名)
```

### 示例

```text
path1 = "c:/楚河脚本/脚本目录/01.txt"
path2 = "c:/楚河脚本/脚本目录/02.txt"

tn1 = 创建线程("线程1", path1)
tn2 = 创建线程("线程2", path2)

线程运行(tn1)
线程运行(tn2)

i = 5
循环 0 小于 1
	println("主线程：还剩", i, "秒后停止线程2")
	等待(1000)
	i = i - 1

	如果 i 等于 0
		跳出循环
	否则
	如果完成
循环完成

线程停止(tn2)

println("线程2已停止！！！！！！！！")
等待(5000)

线程停止(tn1)

i = 0
循环 i 小于 10
	println("现在只剩下主线程了吧", i)
	等待(1000)

	i = i + 1
循环完成

线程销毁(tn1)
线程运行(tn1)

线程销毁(tn1)
线程销毁(tn2)

循环 0 小于 1
	println("hello")
	等待(1000)
循环完成
```

> 注意：线程销毁后，如果需要重新使用，应重新创建线程。线程名称与线程变量的具体生命周期应以实际运行行为为准。

## 18. 图鉴识别

### 功能

使用图鉴识别服务进行图片识别。

### 语法

```text
图鉴识别(图片路径, 用户名, 密码, 识别类型数字, 备注信息)
```

官方网站：

```text
http://www.ttshitu.com/login.html
```

### 识别类型

常见类型包括：

* `1`：纯数字
* `1001`：纯数字2
* `2`：纯英文
* `1002`：纯英文2
* `3`：数英混合
* `1003`：数英混合2
* `4`：闪动 GIF
* `7`：无感学习
* `11`：计算题
* `1005`：快速计算题
* `16`：汉字
* `32`：通用文字识别
* `66`：问答题
* `49`：reCAPTCHA 图片识别
* `29`：旋转类型
* `19`：1 个坐标
* `20`：3 个坐标
* `21`：3～5 个坐标
* `22`：5～8 个坐标
* `27`：1～4 个坐标
* `48`：轨迹类型
* `18`：缺口识别
* `53`：拼图识别

### 示例

```text
path = "c:/相册/工具/验证图.png"

str = 图鉴识别(path, "你的用户名", "你的密码", 20, "")

显示(str)
等待(1000)

sepStr = "|"
list = 分离字符串(str, sepStr, 0)

i = 0
length = 获取数组长度(list)

循环 i 小于 length
	tempStr = list[i]

	显示("tempStr:", tempStr)
	等待(1000)

	xStr = 拷贝方向字符串(tempStr, ",", 1, 0)
	yStr = 拷贝方向字符串(tempStr, ",", 2, 0)

	显示(xStr, "-", yStr)
	等待(1000)

	i = i + 1
循环完成
```

# AI 使用注意事项

1. `运行一个脚本文件`、`运行一个脚本文件并拷贝变量`、`运行一个js文件`、`定时运行一个脚本文件`、`定时运行一个脚本文件_北京时间` 是不同命令，不得混用。
2. `中断脚本()` 与 `停止脚本()` 的作用不同：前者用于中断当前脚本文件，后者相当于执行停止操作。
3. `线程停止()` 和 `线程销毁()` 不同：停止线程不会释放线程单元，销毁线程才释放资源。
4. `创建线程()` 只创建线程，不代表开始执行脚本；需要使用 `线程运行()` 开始运行。
5. `安装模块()` 用于安装其他脚本文件中的模块。
6. `设置全局变量()`、`获取全局变量()`、`删除全局变量()`、`清空全局变量()`处理普通全局变量。
7. `设置全局变量lg()` / `获取全局变量lg()` / `删除全局变量lg()` / `清空全局变量lg()`专门处理全局 LortImage。
8. `设置全局变量bi()` / `获取全局变量bi()` / `删除全局变量bi()` / `清空全局变量bi()`专门处理全局 BufferedImage。
9. `umi识别bi`、`umi识别多行bi`、`umi查找多行中心坐标bi`、`umi查找多行多位置中心坐标bi` 均支持直接截取屏幕区域和使用已有 `bi` 两种形式。
10. 本文件中的 JS 代码属于 JS 文件内部代码，不应把 `js start` / `js end` 中的内容当作普通楚河脚本语法。
11. 所有命令名称必须保持与本文档一致，不得根据其他编程语言或其他自动化软件自行创造相似命令。
12. 如果某个命令的具体行为没有在官方资料中确认，不得自行推测其参数、返回值或内部实现。
