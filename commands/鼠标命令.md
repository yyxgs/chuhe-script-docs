# 楚河脚本鼠标命令

本文档记录楚河脚本中已经确认的鼠标相关命令。

生成楚河脚本时，命令名称、参数顺序和调用方式必须以本文档为准，不得根据其他编程语言自行推测。

---

## 1. 鼠标左键点击

### 语法

```text
鼠标左键点击(x, y)
```

### 参数

* `x`：鼠标点击位置的 X 坐标。
* `y`：鼠标点击位置的 Y 坐标。

### 示例

```text
鼠标左键点击(500, 300)
```

## 4. 鼠标左键随机点击

### 语法

```text
鼠标左键随机点击(x, y, 最小等待时间, 最大等待时间, 最小偏移, 最大偏移)
```

### 参数

* `x`：基础 X 坐标。
* `y`：基础 Y 坐标。
* `最小等待时间`：随机等待时间的最小值，单位为毫秒。
* `最大等待时间`：随机等待时间的最大值，单位为毫秒。
* `最小偏移`：随机坐标偏移的最小值。
* `最大偏移`：随机坐标偏移的最大值。

### 示例

```text

```

## 15. 获取鼠标位置

### 语法

```text
获取鼠标位置()
```

返回当前鼠标坐标。

通常配合 `x()` 和 `y()` 使用。

### 示例

```text
mousePos = 获取鼠标位置()
x1 = x(mousePos)
y1 = y(mousePos)
显示("这个坐标的x是", x1, ", y是", y1)
等待(1000)
鼠标左键点击(x1, y1)
```

## 16. 鼠标对角线拖动

### 语法

```text
鼠标对角线拖动(左上角x, 左上角y, 右下角x, 右下角y, 步长, 步时)
```

### 参数

* `左上角x`：起始区域左上角 X 坐标。
* `左上角y`：起始区域左上角 Y 坐标。
* `右下角x`：结束区域右下角 X 坐标。
* `右下角y`：结束区域右下角 Y 坐标。
* `步长`：拖动过程中的步长。
* `步时`：每一步的时间参数。

### 示例

```text
鼠标对角线拖动(100, 100, 500, 500, 10, 20)
```

## 22. 后台鼠标左键点击

### 语法

```text

```

对指定窗口句柄执行后台鼠标左键点击。

### 参数

* 第一个参数：窗口句柄变量名称。
* `x`：点击位置 X 坐标。
* `y`：点击位置 Y 坐标。

### 示例

```text

后台鼠标左键点击("hwnd1", 100, 200)
```

## AI 生成注意事项

### 1. 命令名称必须准确

例如：

```text
鼠标左键点击(500, 300)
```

不要自行改写成其他名称。

### 2. 坐标必须使用英文逗号

正确：

```text
鼠标左键点击(500, 300)
```

不要使用中文逗号：

```text
鼠标左键点击(500，300)
```

### 3. 不要把教程说明文字当成代码

教程中为了说明功能而写在代码后面的文字属于说明信息，不代表楚河脚本支持行尾注释。

### 4. 鼠标监听线程的使用限制

`开启鼠标监听线程()` 不能在同一次脚本软件运行期间重复开启。

### 5. 后台点击需要窗口句柄

使用 `后台鼠标左键点击` 时，应先获得对应窗口句柄。

### 6. 不确定的参数不要自行推测

如果某个命令的参数、返回值或限制没有在官方资料中明确确认，应先核实，不得根据其他自动化软件或编程语言的行为推测。
