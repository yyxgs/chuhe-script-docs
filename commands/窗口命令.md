## 2. 提示窗口化

### 命令介绍

将脚本窗口变成长方形的提示窗口。

在代码最前面使用：

```text
提示窗口化()
等待(1000)
```

点击运行后，脚本会自动变成提示窗口。

如果要还原代码窗口，可以点击长方形提示窗口的 `X`。

也可以使用**鼠标右键点击运行按钮**，让脚本变成长方形提示窗口。此时可以点击长方形提示窗口，再使用脚本快捷键 `F10` 停止、`F7` 运行。

如果不希望运行后变成提示窗口，删除代码最前面的 `提示窗口化()` 和 `等待(1000)` 即可。

### 参数形式

#### 无参数

```text
提示窗口化()
```

使用默认字体大小和窗口位置。

#### 设置字体大小

```text
提示窗口化(字体大小)
```

示例：

```text
提示窗口化(30)

显示("提示窗口化完成")
```

#### 设置字体大小和窗口位置

```text
提示窗口化(字体大小, x, y)
```

示例：

```text
提示窗口化(30, 500, 600)

显示("提示窗口化完成")
```

#### 设置字体大小、位置和窗口大小

```text
提示窗口化(字体大小, x, y, 宽度, 高度)
```

示例：

```text
提示窗口化(30, 500, 600, 300, 200)

显示("提示窗口化完成")
```

#### 设置是否置顶

```text
提示窗口化(字体大小, x, y, 宽度, 高度, 置顶方式)
```

示例：

```text
提示窗口化(30, 500, 600, 300, 200, 0)

显示("提示窗口化完成")
```

教程示例中 `0` 表示取消窗口置顶。

### AI 注意事项

`提示窗口化` 存在多种参数形式，生成代码时应根据实际需求选择对应形式。

## 5. 设置窗口位置和大小

### 命令介绍

设置指定窗口的位置、大小和显示层级。

### 语法

```text
设置窗口位置和大小(窗口名称, 显示层级, x, y, 窗口宽度, 窗口高度, 方式数值)
```

### 参数

1. `窗口名称`：窗口的名称。
2. `显示层级`：

   * `-1`：最前
   * `1`：最底
3. `x`：窗口 X 坐标。
4. `y`：窗口 Y 坐标。
5. `窗口宽度`：窗口宽度。
6. `窗口高度`：窗口高度。
7. `方式数值`：设置方式，例如：

   * `1`：设置窗口的位置
   * `2`：设置窗口的大小

### 示例

```text
name = "窗口的名称"

设置窗口位置和大小(name, -1, 300, 500, 500, 500, 1)
```

## 6. 设置窗口位置和大小文本中

### 命令介绍

设置窗口的位置和大小，并从文本文件中直接读取窗口名称。

### 语法

```text
设置窗口位置和大小文本中(窗口名称文本路径, 窗口名称所在行, 显示层级, x, y, 窗口宽度, 窗口高度, 方式数值)
```

### 参数

1. `窗口名称文本路径`：保存所有窗口名称的文本路径。
2. `窗口名称所在行`：要设置的窗口名称在文本中的第几行。
3. `显示层级`：

   * `-1`：最前
   * `1`：最底
4. `x`：窗口 X 坐标。
5. `y`：窗口 Y 坐标。
6. `窗口宽度`：窗口宽度。
7. `窗口高度`：窗口高度。
8. `方式数值`：

   * `1`：设置窗口的位置
   * `2`：设置窗口的大小

### 示例

```text
path = "c:/楚河脚本/资源目录/所有窗口名称.txt"

设置窗口位置和大小文本中(path, 13, -1, 300, 500, 500, 500, 1)
```


### 参数

1. `显示层级`：

   * `-1`：最前
   * `1`：最底
2. `x`：窗口 X 坐标。
3. `y`：窗口 Y 坐标。
4. `窗口宽度`：窗口宽度。
5. `窗口高度`：窗口高度。
6. `方式数值`：

   * `1`：设置窗口的位置
   * `2`：设置窗口的大小

### 示例

## 8. 获取窗口位置和大小鼠标位置

### 命令介绍

获取鼠标所在窗口的位置和大小。

返回一个包含 4 个元素的数组，保存窗口的位置和大小坐标。

### 语法

```text
获取窗口位置和大小鼠标位置()
```

### 返回值

返回数组：

```text
[左X, 左Y, 宽度, 高度]
```

### 示例

```text
倒计时显示("请在 ", 10, " 秒内将鼠标放在要获取的窗口上")

indexList = 获取窗口位置和大小鼠标位置()

显示("鼠标所在窗口位置是: ", indexList[0], ", ", indexList[1], ", 大小是: ", indexList[2], ", ", indexList[3])
```

## 9. 获取鼠标位置句柄

### 命令介绍

将鼠标放在指定窗口的位置，可以获取该位置控件的句柄。

### 语法

```text
获取鼠标位置句柄("句柄变量名")
```

### 参数

* `句柄变量名`：保存获取到的窗口或控件句柄的变量名。

### 示例

```text
倒计时显示("请在 ", 10, " 秒内将鼠标放在要获取的窗口上")

获取鼠标位置句柄("hwnd1")

显示("已获取完成")
```

## 10. 后台鼠标左键点击

### 命令介绍

对指定句柄进行后台鼠标左键点击。

### 语法

```text
后台鼠标左键点击(句柄变量名, x, y)
```

### 参数

* `句柄变量名`：通过 `获取鼠标位置句柄` 获取的句柄变量名。
* `x`：点击位置 X 坐标。
* `y`：点击位置 Y 坐标。

### 示例

```text
鼠标移动(2079, 235)

等待(500)

获取鼠标位置句柄("hwnd1")

println("获取成功")

循环 0 小于 1
    后台鼠标左键点击("hwnd1", 100, 100)
    等待(500)
循环完成
```

## 11. 弹出一个背景色窗口

### 命令介绍

弹出一个带背景颜色的窗口，用于方便核对窗口的位置和大小。

### 语法

```text
弹出一个背景色窗口(标题名称, startX, startY, endX, endY, 背景颜色字符串)
```

### 参数

* `标题名称`：窗口标题。
* `startX`：左上角 X 坐标。
* `startY`：左上角 Y 坐标。
* `endX`：右下角 X 坐标。
* `endY`：右下角 Y 坐标。
* `背景颜色字符串`：背景颜色的字符串。

### 示例

```text
弹出一个背景色窗口("浏览器的大小", 100, 100, 800, 800, "FF0000")
```

# AI 注意事项

1. `提示窗口化()` 可以将脚本窗口转换为提示窗口，并存在多种参数形式。
2. `设置窗口最前()` 用于将脚本窗口置顶并获取焦点。
3. `设置窗口位置和大小`、`设置窗口位置和大小文本中`、`设置窗口位置和大小鼠标位置` 是三种不同的窗口设置方式，不要混淆。
4. `获取窗口位置和大小鼠标位置()` 返回的是数组。
5. `获取鼠标位置句柄()` 获取的句柄可以用于 `后台鼠标左键点击()`。
6. 窗口显示层级参数中，教程明确给出了 `-1` 表示最前、`1` 表示最底。
7. `方式数值` 已确认 `1` 为设置窗口位置、`2` 为设置窗口大小。
8. 不得根据 Windows API 或其他编程语言自行推测本文档没有说明的参数值。
9. 示例中的窗口名称、路径和坐标仅用于演示，生成实际脚本时应根据用户实际环境修改。
