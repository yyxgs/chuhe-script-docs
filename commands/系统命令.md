# 楚河脚本系统命令

本文档记录楚河脚本中已经确认的系统相关命令。

这些命令涉及剪切板、文件打开、CMD、PowerShell、声音、窗口、坐标工具、进程、屏幕、多显示器等功能。

## 1. 获取剪切板字符串

### 功能

获取剪切板中的字符串内容。

### 语法

```text
获取剪切板字符串()
```

### 返回值

返回剪切板中的字符串。

### 示例

```text
显示("正在读取剪切板...")

len = 0
str = ""

循环 0 小于 1
	str = 获取剪切板字符串()

	len = 获取字符串长度(str)
	如果 len 大于 0
		跳出循环
	否则
	如果完成
循环完成

prompt = 拼接字符串("获取剪切板的内容是: ", str)
显示(prompt)
等待(1000)
```

### 注意

教程中通过循环重复读取剪切板，是为了处理某些情况下第一次读取不到内容的问题。

## 3. 弹窗获取剪切板写到文本

### 功能

使用弹窗方式获取剪切板字符串，并将结果写入指定文本文件。

该命令用于解决 `获取剪切板字符串()` 有时获取不到内容的问题。

### 语法

```text
弹窗获取剪切板写到文本(文本路径, 宽, 高, x, y)
```

### 参数

* `文本路径`：保存剪切板内容的文本路径
* `宽`：窗口宽度
* `高`：窗口高度
* `x`：窗口 X 坐标
* `y`：窗口 Y 坐标

### 示例

```text
path = "c:/楚河脚本/资源目录/临时剪切板文本.txt"

弹窗获取剪切板写到文本(path, 400, 300, 100, 100)

等待(500)

str = 读取文本字符串(path)
显示(str)
```

## 9. 打开文件

### 功能

使用系统默认方式打开指定文件。

相当于通过系统打开该文件：

* 文本文件通常使用默认文本编辑器打开
* 歌曲通常使用默认播放器播放
* 视频通常使用默认播放器播放
* `.exe` 文件可以直接启动

### 语法

```text
打开文件(文件路径)
```

### 示例

```text
显示("播放歌曲")
打开文件("d:/演员.mp3")
```

```text
显示("打开计算器")
打开文件("c:/windows/system32/calc.exe")
```

### 注意

文件路径通常需要包含正确的文件扩展名，例如：

```text
.txt
.mp3
.mp4
.exe
```

## 12. 弹出一个提示窗口

### 功能

弹出自定义提示窗口。

支持静态显示和动态倒计时显示两种形式。

### 静态显示

最后一个参数使用空字符串：

```text
弹出一个提示窗口(提示内容, 窗口宽度, 窗口高度, 字体名称, 字体大小, 背景色, 字体色, 自动关闭秒数, 窗口x, 窗口y, 是否置顶, "")
```

### 动态显示

最后一个参数不能是空字符串，例如使用：

```text
"秒"
```

语法：

```text
弹出一个提示窗口(提示内容, 窗口宽度, 窗口高度, 字体名称, 字体大小, 背景色, 字体色, 自动关闭秒数, 窗口x, 窗口y, 是否置顶, "秒")
```

### 参数

1. `提示内容`
2. `窗口宽度`
3. `窗口高度`
4. `字体名称`
5. `字体大小`
6. `背景色`
7. `字体色`
8. `自动关闭秒数`
9. `窗口x`
10. `窗口y`
11. `是否置顶`
12. 最后一个参数用于区分静态/动态显示

### 示例

```text
弹出一个提示窗口("优雅深蓝配米黄：深蓝字体 米黄色背景", 800, 300, "宋体", 30, "2D3E50", "F9E79F", 5, 0, 0, 1, "")
等待(1000)
```

## 25. 播放声音指定设备

### 功能

通过设备名称关键词模糊匹配音频播放设备，并从指定设备播放 MP3 文件。

### 语法

```text
播放声音指定设备("设备关键词", "mp3路径", 播放时长, 播放次数, "编码格式")
```

### 参数

1. `设备关键词`：设备名称关键词，模糊匹配，区分大小写
2. `mp3路径`：MP3 文件路径
3. `播放时长`：播放秒数，填写 `0` 表示播放完整文件
4. `播放次数`：播放次数
5. `编码格式`：Windows 中文系统填写 `"GBK"`，其他情况填写 `"UTF-8"`

### 示例

播放完整 MP3，播放 1 次：

```text
播放声音指定设备("AYINO", "c:/sound/alert.mp3", 0, 1, "GBK")
```

只播放前 3 秒，播放 2 次：

```text
播放声音指定设备("AYINO", "c:/sound/alert.mp3", 3, 2, "GBK")
```

## 28. powershell

### 功能

运行 PowerShell 命令，并可以获取 PowerShell 的输出结果。

### 语法

```text
powershell(命令字符串)
```

或：

```text
powershell(命令字符串, 编码方式)
```

### 参数

* `命令字符串`：需要执行的 PowerShell 命令
* `编码方式`：输出编码方式

### 返回值

返回 PowerShell 命令的输出结果。

### 示例

```text
result = powershell("Get-Date")
println(result)
```

### 注意

PowerShell 命令本身不是楚河脚本语法。

例如以下内容：

```text
powercfg /change standby-timeout-ac 0
powercfg /change standby-timeout-dc 0
```

属于 Windows 命令，应作为字符串传给 `powershell()`，而不是直接作为楚河脚本语句。

例如：

```text
result = powershell("powercfg /change standby-timeout-ac 0")
println(result)
```

9. 系统命令与其他类别的命令可以组合使用，例如剪切板命令可以与文本命令、字符串命令、循环命令配合使用。
10. 如果某个系统功能没有在本文档中出现，不得仅根据 Windows 或其他编程语言的功能名称推测楚河脚本存在对应命令。
