# 楚河脚本基础语法示例

本文档用于展示楚河脚本最基础、最常见的代码结构。

这些示例主要用于帮助 ChatGPT、Claude 以及其他 AI 理解楚河脚本的基本写法。

示例中的语法必须遵守：

`language/语言规则.md`

中的正式语言规则。

---

# 1. 变量初始化

楚河脚本中的变量必须先初始化。

```text
i = 0
name = ""
number = 0
```

不要直接使用没有初始化的变量。

错误示例：

```text
i = i + 1
```

正确示例：

```text
i = 0
i = i + 1
```

---

# 2. 显示内容

使用 `显示()` 可以在编辑器左下角的固定提示区域显示内容。

```text
显示("你好")
```

也可以同时显示多个内容：

```text
name = "小明"
age = 18

显示("姓名：", name, " 年龄：", age)
```

---

# 3. println

`println()` 可以输出内容并换行。

```text
println("你好")
println("楚河脚本")
```

也可以输出多个内容：

```text
name = "小明"
age = 18

println("姓名：", name)
println("年龄：", age)
```

---

# 4. 等待

使用 `等待()` 让脚本暂停指定的毫秒数。

```text
等待(1000)
```

表示等待 1000 毫秒。

也可以使用倒计时显示：

```text
等待(3000, 1)
```

---

# 5. 如果判断

楚河脚本的 `如果` 结构必须完整使用：

```text
如果 条件
	执行内容
否则
	执行内容
如果完成
```

例如：

```text
i = 10

如果 i 大于 5
	println("i大于5")
否则
	println("i不大于5")
如果完成
```

---

# 6. 如果判断多个条件

可以使用 `并且` 和 `或者`。

例如：

```text
i = 10

如果 i 大于 5 并且 i 小于 20
	println("i在指定范围内")
否则
	println("i不在指定范围内")
如果完成
```

或者：

```text
i = 10

如果 i 等于 5 或者 i 等于 10
	println("i是5或者10")
否则
	println("i不是5也不是10")
如果完成
```

不要使用 `否则如果`。

需要多个条件判断时，应按照楚河脚本正式的 `如果 / 否则 / 如果完成` 结构编写。

---

# 7. 循环

楚河脚本使用：

```text
循环 条件
	循环内容
循环完成
```

例如无限循环：

```text
循环 0 小于 1
	println("循环中")
	等待(1000)
循环完成
```

---

# 8. 使用变量控制循环次数

循环变量必须初始化。

例如循环 3 次：

```text
i = 0

循环 i 小于 3
	println("第", i, "次循环")

	i = i + 1
循环完成
```

循环结束后：

```text
println("循环结束")
```

---

# 9. 跳出循环

使用 `跳出循环` 可以提前结束当前循环。

```text
i = 0

循环 i 小于 10
	println("当前数字：", i)

	如果 i 等于 5
		跳出循环
	否则
	如果完成

	i = i + 1
循环完成

println("循环已经结束")
```

当 `i` 等于 5 时，循环立即结束。

---

# 10. 继续循环

使用 `继续循环` 可以跳过当前循环剩余内容，直接进入下一次循环。

```text
i = 0

循环 i 小于 5

	如果 i 等于 2
		i = i + 1
		继续循环
	否则
	如果完成

	println("当前数字：", i)

	i = i + 1
循环完成
```

---

# 11. 如果与循环组合

`如果` 可以放在 `循环` 内部。

```text
i = 0

循环 i 小于 10

	如果 i 等于 5
		println("找到5")
	否则
		println("当前数字不是5")
	如果完成

	i = i + 1

循环完成
```

这是楚河脚本中常见的嵌套结构。

---

# 12. 字符串变量

字符串可以直接使用双引号表示。

```text
name = "小明"
text = "你好"

println(name)
println(text)
```

字符串之间的处理应使用楚河脚本已经提供的字符串命令。

例如使用 `拼接字符串`：

```text
str1 = "你好"
str2 = "世界"

str3 = 拼接字符串(str1, str2)

println(str3)
```

不要使用其他编程语言中的字符串拼接语法代替楚河脚本命令。

例如不要写：

```text
str3 = str1 + str2
```

---

# 13. 数字变量

数字变量可以直接初始化：

```text
a = 10
b = 20
```

可以进行数字运算：

```text
a = 10
b = 20

result = 计算加减乘除(a, b, "+")
println(result)
```

具体命令参数必须以对应的官方命令文档为准。

---

# 14. 数组

数组下标从 `0` 开始。

例如：

```text
list[0] = 777
list[1] = 888
list[2] = 999
```

获取数组长度：

```text
length = 获取数组长度(list)

println("数组长度：", length)
```

遍历数组：

```text
i = 0
length = 获取数组长度(list)

循环 i 小于 length
	println(list[i])

	i = i + 1
循环完成
```

---

# 15. 获取鼠标位置

可以使用 `获取鼠标位置()` 获取当前鼠标位置。

```text
获取鼠标位置()

mouseX = x()
mouseY = y()

println("鼠标X：", mouseX)
println("鼠标Y：", mouseY)
```

# 16. 鼠标移动

例如移动到坐标：

```text
鼠标移动(500, 300)
```

然后等待：

```text
等待(500)
```

# 19. 循环查找并提前结束

这是图色脚本中常见的结构：

```text
i = 0

循环 i 小于 10

	result = 获取鼠标位置()

	如果 result 等于 ""
		继续循环
	否则
	如果完成

	如果 i 等于 5
		跳出循环
	否则
	如果完成

	i = i + 1

循环完成
```

实际使用时，应根据具体命令返回值编写判断条件。

# 20. 标记与跳转

楚河脚本支持定义标记：

```text
标记 开始

println("执行一次")

跳到标记 开始
```

标记名称用于配合 `跳到标记` 进行跳转。

使用时需要注意避免产生无法结束的逻辑。

---

# 21. 注释

楚河脚本支持单行注释。

注释必须从一行的开头开始：

```text
// 这是一个注释
println("你好")
```

不能把注释放在命令后面：

```text
println("你好") // 这是错误的注释写法
```

楚河脚本还支持块注释：

```text
/*
这是块注释
可以包含多行内容
*/
```

`/*` 和 `*/` 应分别独占一行。

# 22. 一个基础综合示例

下面将变量、循环、判断和显示组合起来：

```text
name = "小明"
i = 0

显示("开始执行脚本")

循环 i 小于 5

	println("你好，", name, "，当前次数：", i)

	如果 i 等于 3
		println("当前已经执行到第3次")
	否则
		println("当前不是第3次")
	如果完成

	i = i + 1

	等待(500)

循环完成

显示("脚本执行完成")
```

# 23. AI 生成基础代码时的检查规则

生成楚河脚本后，应至少检查以下内容：

1. 每条语句是否独占一行。
2. 变量是否已经初始化。
3. 是否错误使用 `i++` 等其他语言语法。
4. 是否错误使用 `str3 = str1 + str2` 进行字符串拼接。
5. `如果` 是否使用完整的 `如果 / 否则 / 如果完成` 结构。
6. 是否错误使用 `否则如果`。
7. `循环` 是否使用对应的 `循环完成`。
8. 是否正确使用 `继续循环` 和 `跳出循环`。
9. 是否存在不允许的嵌套函数调用。
10. 是否在没有官方资料依据的情况下自行创造命令。
11. 命令参数是否与对应的官方命令文档一致。
12. 注释是否符合楚河脚本的注释规则。
13. 缩进是否使用 Tab。
14. 示例是否是真实的楚河脚本，而不是其他编程语言的伪代码。
