# 1. 拼接字符串

## 语法

```text
拼接字符串("字符串1", "字符串2")
```

可以传入多个字符串参数。

## 功能

将多个字符串按照参数顺序拼接成一个字符串。

## 示例

```text
str = 拼接字符串("你好", "世界")
显示(str)
```

多个参数：

```text
str = 拼接字符串("我", "喜欢", "楚河脚本")
显示(str)
```

## 注意

* 参数数量可以根据实际需要增加。
* 参数之间使用英文逗号 `,`。
* 返回拼接后的字符串。

# 2. 拼接字节字符串

## 语法

```text
拼接字节字符串("字节字符串1", "字节字符串2")
```

可以传入多个参数。

## 功能

将多个字节字符串拼接起来。

楚河脚本的字节字符串使用 `-` 分隔字节。

## 示例

```text
str = 拼接字节字符串("E4-BD-A0", "E5-A5-BD")
显示(str)
```

## 注意

第一个参数同样属于字节字符串，不是普通字符串。

# 4. 对比字符串

## 语法

```text
对比字符串(字符串1, 字符串2)
```

## 返回值

* `是`：两个字符串相同
* `否`：两个字符串不同

## 示例

```text
str1 = "你好"
str2 = "你好"

如果 对比字符串(str1, str2) 等于 是
    显示("两个字符串相同")
否则
    显示("两个字符串不同")
如果完成
```

## 注意

返回的是楚河脚本字符串值 `是` 或 `否`。

# 5. 查找字符串位置

## 语法

```text
查找字符串位置(总字符串, 要查找的字符串)
```

也支持指定跳过次数：

```text
查找字符串位置(总字符串, 要查找的字符串, 跳过次数)
```

## 功能

在总字符串中查找指定字符串的位置。

## 示例

```text
str = "西瓜苹果西瓜香蕉"
result = 查找字符串位置(str, "西瓜")
显示(result)
等待(1000)
```

指定跳过次数：

```text
str = "西瓜苹果西瓜香蕉"
result = 查找字符串位置(str, "西瓜", 1)
显示(result)
等待(1000)
```

## 注意

第三个参数用于控制查找时跳过的匹配次数。

# 9. 字符串里拷贝字符串_字符串

## 语法

```text
字符串里拷贝字符串_字符串(总字符串, 起始字符串, 结束字符串, 起始偏移, 结束偏移)
```

## 功能

通过指定开始字符串和结束字符串，在总字符串中拷贝中间的一段字符串。

## 参数

* 第1个参数：总字符串
* 第2个参数：起始字符串
* 第3个参数：结束字符串
* 第4个参数：起始偏移
* 第5个参数：结束偏移

## 注意

这是一个独立存在的命令。

不要将它与：

```text
字符串里拷贝字符串(...)
```

或：

```text
字符串里更改字符串(...)
```

混淆。

# 10. 拷贝方向字符串

## 语法

```text
拷贝方向字符串(字符串, 分隔字符串, 方向, 是否包含分隔字符串)
```

## 参数

* 第1个参数：总字符串
* 第2个参数：用于分隔的字符串
* 第3个参数：拷贝方向

  * `1`：向前
  * `2`：向后
* 第4个参数：是否包含分隔字符串

  * `0`：不包含
  * `1`：包含

## 示例

```text
str = "abc-def-ghi"
result = 拷贝方向字符串(str, "-", 1, 0)
显示(result)
```

## 注意

第三个参数是方向参数，不是第二个参数。

# 11. 字符串里更改字符串

## 语法

```text
字符串里更改字符串(总字符串, 要替换的字符串, 新字符串)
```

必须使用 **3 个参数**。

## 参数

* 第1个参数：总字符串
* 第2个参数：要替换的字符串
* 第3个参数：替换后的新字符串

## 功能

将总字符串中指定的字符串替换成新的字符串。

## 示例

```text
result = 字符串里更改字符串("hello world", "world", "楚河")
显示(result)
```

结果：

```text
hello 楚河
```

## 注意

不要将此命令与已经删除的：

```text
字符串里更改字符串_字符串
```

混淆。

`字符串里更改字符串_字符串` 不属于当前确认的命令。

```text

```

可以传入多个需要匹配的字符串。

## 功能

将字符串中所有匹配到的指定字符串统一替换成同一个新字符串。

## 匹配规则

当多个匹配字符串可能同时匹配当前位置时，优先匹配较长的字符串。

替换过程不会因为刚刚替换出的新字符串再次参与匹配而产生连续替换。

## 示例

```text
str = "逗饱我读宝你好"

result = 字符串里全都更改为一个字符串(str, "豆包", "逗饱", "读宝")
显示(result)
```

结果：

```text
豆包豆包你好
```

## 注意

匹配字符串的数量可以根据实际需要增加。

如果参数数量不足以进行有效匹配，则返回原字符串。
