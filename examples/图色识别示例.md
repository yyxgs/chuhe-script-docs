# 楚河脚本图色识别示例

本文档用于展示楚河脚本中截图、找图、找色、坐标处理以及鼠标操作的常见组合方式。

示例中的具体命令参数以：

* `commands/图色命令.md`
* `commands/坐标与转换命令.md`
* `commands/鼠标命令.md`
* `language/语言规则.md`

中的正式定义为准。

---

# 1. 截取屏幕区域

使用 `截图()` 保存指定区域：

```text
截图(0, 0, 1920, 1080, "c:/楚河脚本/截图.png")
```

例如截图后等待：

```text
截图(0, 0, 1920, 1080, "c:/楚河脚本/截图.png")
等待(500)
```

---

# 2. 截图后查看图片

可以使用截图和图片查看器组合：

```text
path = "c:/楚河脚本/截图.png"

截图(0, 0, 1920, 1080, path)

打开图片查看器(path, 0)
```

---

# 3. 找图

在屏幕截图中寻找指定图片：

```text
screenPath = "c:/楚河脚本/截图.png"
templatePath = "c:/楚河脚本/资源目录/要找的图.png"

result = 找图(screenPath, templatePath)

println("找到的位置：", result)
```

---

# 4. 找图后获取坐标

如果找图返回坐标字符串，可以使用 `x()` 和 `y()` 获取坐标：

```text
result = 找图("c:/楚河脚本/截图.png", "c:/楚河脚本/资源目录/要找的图.png")

xPos = x(result)
yPos = y(result)

println("X：", xPos)
println("Y：", yPos)
```

---

# 5. 找图后点击

可以把找图结果转换成坐标，然后执行鼠标点击：

```text
result = 找图("c:/楚河脚本/截图.png", "c:/楚河脚本/资源目录/要找的图.png")

xPos = x(result)
yPos = y(result)

鼠标左键点击(xPos, yPos)
```

---

# 6. 判断是否找到图片

找图结果可以与 `如果` 结合：

```text
result = 找图("c:/楚河脚本/截图.png", "c:/楚河脚本/资源目录/要找的图.png")

xPos = x(result)

如果 xPos 大于 -1
	println("找到目标图片")
否则
	println("没有找到目标图片")
如果完成
```

# 10. 直接读取屏幕进行图色判断

# 14. 比较屏幕区域变化

可以使用 `比图zcfbi()` 判断指定区域发生了多少像素变化：

# 19. 找图循环重试

自动化脚本中，经常需要等待目标出现。

例如循环检查：

```text
i = 0
found = 0

循环 i 小于 10

	result = 找图("c:/楚河脚本/截图.png", "c:/楚河脚本/资源目录/要找的图.png")

	xPos = x(result)

	如果 xPos 大于 -1
		found = 1
		跳出循环
	否则
		等待(500)
	如果完成

	i = i + 1

循环完成

如果 found 等于 1
	println("找到目标")
否则
	println("等待后仍未找到目标")
如果完成
```

# 26. 图色识别与循环综合示例

下面是一个比较完整的图色自动化结构：

```text
screenPath = "c:/楚河脚本/截图.png"
buttonPath = "c:/楚河脚本/资源目录/要找的图.png"

i = 0
found = 0

循环 i 小于 20

	截图(0, 0, 1920, 1080, screenPath)

	result = 找图(screenPath, buttonPath)

	xPos = x(result)

	如果 xPos 大于 -1
		yPos = y(result)

		println("找到按钮：", xPos, ",", yPos)

		鼠标左键点击(xPos, yPos)

		found = 1

		跳出循环
	否则
		println("第", i, "次没有找到")

		等待(500)
	如果完成

	i = i + 1

循环完成

如果 found 等于 1
	println("操作完成")
否则
	println("在规定次数内没有找到目标")
如果完成
```

# AI 使用注意事项

1. 楚河脚本常用截图路径可以使用：

   `c:/楚河脚本/截图.png`

2. 楚河脚本常用找图资源路径可以使用：

   `c:/楚河脚本/资源目录/要找的图.png`

3. 以上路径是常见示例路径，实际脚本可以根据需要使用其他路径。

4. 图色识别命令的参数必须以 `commands/图色命令.md` 为准。

5. 不要根据其他图色软件自行创造参数。

6. 找图、找色等命令的返回值必须按照官方命令文档处理。

7. 坐标字符串可以使用 `x()`、`y()` 或 `转换为坐标()` 等已经确认的命令进行处理。

8. 识别结果需要与 `如果` 结合时，应先根据实际返回值进行判断。

9. 图色识别与鼠标操作组合时，应明确区分“识别坐标”和“实际屏幕坐标”。

10. 使用区域识别时，要特别注意区域左上角坐标与返回坐标的关系。

11. 使用 `bi`、`LortImage` 等图像对象时，应按照对应命令的变量规则操作。

12. 不要因为命令名称相似，就把普通图片命令、`bi` 命令和 `LortImage` 命令混用。

13. 图色识别通常需要等待目标出现，因此可以使用循环和 `等待()` 进行重复检测。

14. 循环计数变量必须初始化。

15. 楚河脚本不使用 `i++`。

16. `如果` 必须使用完整的 `如果 / 否则 / 如果完成` 结构。

17. 不要使用 `否则如果`。

18. 示例中的图片路径和坐标仅用于演示，不代表实际软件界面的固定位置。
