# 楚河脚本综合示例

本文档用于展示楚河脚本中多个已经确认的功能如何组合使用。

这些示例主要用于帮助 ChatGPT、Claude 以及其他 AI 理解真实的楚河脚本结构。

本文档中的命令必须以 `commands/` 目录中的正式命令文档为准。

---

# 1. 基础脚本结构

一个简单的楚河脚本可以由变量、显示、等待和判断组成：

```text
name = "小明"
i = 0

显示("脚本开始")
println("姓名：", name)

如果 i 等于 0
	println("i的初始值是0")
否则
	println("i不是0")
如果完成

等待(1000)

显示("脚本结束")
```

---

# 2. 循环执行任务

使用循环执行固定次数的任务：

```text
i = 0

循环 i 小于 5

	println("正在执行第", i, "次")

	等待(500)

	i = i + 1

循环完成

println("执行完成")
```

---

# 3. 循环 + 判断

根据循环变量执行不同操作：

```text
i = 0

循环 i 小于 10

	如果 i 等于 5
		println("当前是5")
	否则
		println("当前是：", i)
	如果完成

	i = i + 1

循环完成
```


# 7. 循环等待图片出现

如果目标图片不是立即出现，可以循环检测：

```text

imagePath = "c:/楚河脚本/资源目录/要找的图.png"

i = 0
found = 0

循环 i 小于 20

	截图(0, 0, 1920, 1080, screenPath)

	result = 找图(screenPath, imagePath)

	xPos = x(result)

	如果 xPos 大于 -1

		found = 1

		println("找到目标")

		跳出循环

	否则

		println("没有找到，继续等待")

		等待(500)

	如果完成

	i = i + 1

循环完成

如果 found 等于 1
	println("检测成功")
否则
	println("检测超时")
如果完成
```

# 12. 字符串处理 + 显示

可以先拼接字符串，再输出：

```text
name = "小明"
number = 123

message = 拼接字符串("姓名：", name, "，编号：", number)

println(message)
```

不要使用其他编程语言的字符串加法：

```text
str3 = str1 + str2
```

这不是楚河脚本规定的字符串拼接方式。

# 25. 一个完整的自动化流程

下面将截图、找图、循环、判断、鼠标点击和等待组合起来：

```text

targetPath = "c:/楚河脚本/资源目录/要找的图.png"

i = 0

循环 i 小于 30

	截图(0, 0, 1920, 1080, screenPath)

	result = 找图(screenPath, targetPath)

	xPos = x(result)

	如果 xPos 大于 -1

		yPos = y(result)

		显示("找到目标，准备点击")

		鼠标左键点击(xPos, yPos)

		等待(500)

		success = 1

		跳出循环

	否则

		显示("正在等待目标出现")

		等待(500)

	如果完成

	i = i + 1

循环完成

如果 success 等于 1
	显示("自动化操作完成")
否则
	显示("没有找到目标")
如果完成
```

# 26. 综合脚本的基本结构

实际编写较大的楚河脚本时，可以按照下面的思路组织：

```text
初始化变量

准备文件路径

准备图片路径

准备其他参数

开始执行主要流程

循环

	执行一个步骤

	获取结果

	判断结果

	如果成功
		执行下一步
	否则
		等待或者继续循环
	如果完成

循环完成

输出最终结果
```

# AI 使用注意事项

1. 综合示例只能使用已经在官方命令文档中确认的命令。

2. 不要因为示例中存在某种组合，就推测不存在于命令文档中的新功能。

3. 示例中的命令组合不代表所有命令都可以任意组合。

4. 每条语句独立占一行。

5. 不使用嵌套函数调用。

6. 变量必须先初始化。

7. 不使用 `i++`。

8. 不使用 `str1 + str2` 进行字符串拼接。

9. `如果` 必须完整使用：

   `如果 / 否则 / 如果完成`

10. 不使用 `否则如果`。

11. `循环` 必须使用：

`循环 / 循环完成`

12. 循环条件中的比较必须遵守楚河脚本语言规则。
13. `如果` 条件行和 `循环` 条件行不能直接调用函数。
14. 如果需要使用函数结果作为条件，应先将结果保存到变量。
15. `跳出循环` 用于结束当前循环。
16. `继续循环` 用于进入下一次循环。
17. `标记` 和 `跳到标记` 用于流程跳转。
18. 图色识别返回的坐标、数组等数据必须按照对应命令的返回值规则处理。
19. 截图常用路径：

`c:/楚河脚本/截图.png`

20. 找图资源常用路径：

`c:/楚河脚本/资源目录/要找的图.png`

21. 不要自行创造官方文档中不存在的命令、参数或返回值。
22. 如果某个功能的正式语法没有在官方文档中确认，应明确说明资料不足，而不是猜测。
23. 综合示例的作用是展示真实语法组合，不代表示例中的所有路径、坐标和参数都是固定值。
