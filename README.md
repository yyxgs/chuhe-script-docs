正确理解楚河脚本的语言规则、命令、参数和实际使用方式。

---

## 楚河脚本是什么

楚河脚本是一种独立的自动化脚本语言。

它不是：

* Java
* Python
* JavaScript
* AutoHotkey
* 其他脚本语言

因此，AI 在生成楚河脚本时，不能直接套用其他编程语言的语法。

# AI 应该从哪里开始

如果 AI 第一次学习楚河脚本，建议按照以下顺序阅读：

### 1. AI 使用规则

首先阅读：

`AI.md`

这里说明 AI 生成楚河脚本时必须遵守的基本原则。

### 2. 语言规则

然后阅读：

`language/语言规则.md`

这里定义楚河脚本的基础语言语法。

例如：

* 一行一条语句
* 变量必须初始化
* `如果 / 否则 / 如果完成`
* `循环 / 循环完成`
* `继续循环`
* `跳出循环`
* Tab 缩进
* 注释规则
* 数组规则
* 模块规则
* 脚本执行规则

### 3. 命令文档

然后根据任务需要阅读：

`commands/`

这里记录已经确认存在的楚河脚本命令。

### 4. 示例

最后可以参考：

`examples/`

这里提供完整的真实楚河脚本示例。

# AI 生成楚河脚本的重要规则

生成楚河脚本之前，应先确认所需要的命令是否存在于官方文档中。

不得：

* 自行创造命令
* 自行创造参数
* 自行猜测返回值
* 套用其他语言语法
* 使用伪代码代替真实楚河脚本
* 因为其他语言存在类似功能，就推测楚河脚本也存在

如果官方文档没有足够资料确认某项功能，应明确说明资料不足。

---

# 官方资料优先级

楚河脚本的命令和语言行为应以已经确认的资料为依据：

1. 楚河脚本实际实现
2. 官方教程
3. 已确认的实际运行行为
4. 本仓库其他官方文档

如果发现文档与实际实现存在差异，应进一步核实，而不是自行猜测。

# 示例路径

楚河脚本中常见的截图路径：

```text
c:/楚河脚本/截图.png
```

常见的图片资源路径：

```text
c:/楚河脚本/资源目录/要找的图.png
```

这些只是常用示例路径，不代表所有脚本必须使用这些路径。

# 文档原则

本仓库的目标不是让 AI “猜懂”楚河脚本。

而是通过公开、明确、可验证的资料，让 AI 学习真实的楚河脚本。

因此：

> **不知道的语法不要猜。**

> **没有确认的命令不要编。**

> **实际存在的语法必须准确使用。**
