# 楚河脚本命令文档

本目录用于记录已经确认存在的楚河脚本命令。

这些文档主要用于帮助 ChatGPT、Claude 以及其他 AI 正确理解和生成楚河脚本。

## 使用规则

1. 只能使用本目录中已经确认存在的命令。
2. 命令名称必须与楚河脚本实际命令一致。
3. 命令语法必须以官方文档和实际实现为准。
4. 不得根据其他编程语言的类似功能自行推测楚河脚本命令。
5. 如果某个命令的语法或参数尚未确认，不得编造。
6. 教程中的完整示例不能代替命令本身的正式定义。
7. 命令存在多个参数形式时，应分别记录。
8. 命令示例必须使用真实的楚河脚本语法。

## 命令资料来源

命令定义应以以下资料为依据：

1. 楚河脚本实际实现
2. 官方教程
3. 已确认的实际运行行为
4. 本仓库其他官方文档

如果不同资料存在冲突，应保留冲突并进行核实，不得自行选择一个版本作为正确答案。
