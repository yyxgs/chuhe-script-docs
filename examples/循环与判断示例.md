# 楚河脚本循环与判断示例

本文档用于展示楚河脚本中 `如果`、`循环`、`继续循环`、`跳出循环`、`标记` 和 `跳到标记` 的常见使用方式。

示例中的语法以：

* `language/语言规则.md`
* `commands/如果命令.md`
* `commands/循环命令.md`

中的正式定义为准。

---

# 1. 最基本的如果判断

楚河脚本的判断结构必须完整使用：

```text
如果 条件
	满足条件时执行的内容
否则
	不满足条件时执行的内容
如果完成
```

例如：

```text
i = 10

如果 i 大于 5
	println("i大于5")
否则
	println("i不大于5")
如果完成
```

---

# 2. 判断字符串

```text
name = "小明"

如果 name 等于 "小明"
	println("名字正确")
否则
	println("名字不正确")
如果完成
```

---

# 3. 判断多个条件

可以使用 `并且`：

```text
i = 10
j = 20

如果 i 小于 20 并且 j 大于 10
	println("两个条件都满足")
否则
	println("条件不满足")
如果完成
```

也可以使用 `或者`：

```text
i = 10
j = 20

如果 i 等于 10 或者 j 等于 30
	println("至少一个条件满足")
否则
	println("两个条件都不满足")
如果完成
```

---

# 4. 使用循环执行指定次数

循环计数变量必须先初始化：

```text
i = 0

循环 i 小于 5

	println("当前次数：", i)

	i = i + 1

循环完成
```

这个循环会执行 5 次，`i` 的值依次为：

```text
0
1
2
3
4
```


---

# 6. 使用跳出循环提前结束

`跳出循环` 可以立即结束当前循环：

```text
i = 0

循环 i 小于 10

	println("当前：", i)

	如果 i 等于 5
		println("已经达到5")
		跳出循环
	否则
		println("继续")
	如果完成

	i = i + 1

循环完成

println("循环结束")
```

当 `i` 等于 5 时，循环立即结束。

---

# 7. 使用继续循环

`继续循环` 用于跳过本次循环剩余内容，进入下一次循环。

```text
i = 0

循环 i 小于 10

	如果 i 等于 5
		i = i + 1
		继续循环
	否则
		println("当前数字：", i)
	如果完成

	i = i + 1

循环完成
```

上面的示例中，`i` 等于 5 时不会执行后面的 `println()`。

# 10. 无限循环

楚河脚本可以使用始终成立的条件构造无限循环：

```text
循环 0 小于 1

	println("无限循环")

循环完成
```

通常需要配合 `跳出循环`：

```text
i = 0

循环 0 小于 1

	println("当前：", i)

	如果 i 等于 10
		跳出循环
	否则
		println("继续执行")
	如果完成

	i = i + 1

循环完成
```

# 13. 嵌套判断

# 15. 标记和跳到标记

楚河脚本支持使用：

```text
标记 标记名称
```

以及：

```text
跳到标记 标记名称
```

例如：

```text
标记 开始

println("执行脚本")

跳到标记 开始
```

这样会不断跳回 `开始` 标记。

# 16. 标记配合判断

```text

	println("结束")
否则

```

# 23. 综合示例

下面是一个综合使用循环、判断、跳出循环和图色识别的例子：

```text
screenPath = "c:/楚河脚本/截图.png"
buttonPath = "c:/楚河脚本/资源目录/要找的图.png"

i = 0
found = 0

循环 i 小于 30

	截图(0, 0, 1920, 1080, screenPath)

	result = 找图(screenPath, buttonPath)

	xPos = x(result)

	如果 xPos 大于 -1

		yPos = y(result)

		println("第", i, "次检测找到目标")

		鼠标左键点击(xPos, yPos)

		found = 1

		跳出循环

	否则

		println("第", i, "次检测没有找到")

		等待(500)

	如果完成

	i = i + 1

循环完成

如果 found 等于 1
	println("操作完成")
否则
	println("检测结束，没有找到目标")
如果完成
```

# AI 使用注意事项

1. `如果` 必须使用完整的：

   `如果 / 否则 / 如果完成`

2. 不允许使用 `否则如果`。

3. 循环使用：

   `循环 ...`

   `循环完成`

4. 循环计数变量必须先初始化。

5. 不使用 `i++`。

6. 计数通常使用：

   `i = i + 1`

7. `跳出循环` 用于结束当前循环。

8. `继续循环` 用于跳过当前循环剩余内容。

9. `标记` 和 `跳到标记` 是独立的流程控制方式，不要把它们误认为普通变量。

10. `如果` 条件行不能直接调用函数。

11. `循环` 条件行不能直接调用函数。

12. 判断条件中使用的变量，应先通过独立语句得到。

13. 不要把其他编程语言的 `while`、`for`、`break`、`continue`、`else if` 等语法直接套用到楚河脚本。

14. 嵌套结构必须使用 Tab 缩进保持层级清晰。

15. 示例中的图色路径可以使用：

`c:/楚河脚本/截图.png`

和：

`c:/楚河脚本/资源目录/要找的图.png`
