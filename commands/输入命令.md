# 楚河脚本输入命令

本文档记录楚河脚本中已经确认的输入相关命令。

---

## 1. 输入

### 命令介绍

模拟输入一段字符串。

该命令的原理是将双引号中的内容写入剪切板，然后使用 `Ctrl + V` 模拟粘贴实现输入效果。

### 语法

```text
输入(字符串)
```

### 参数

* `字符串`：要输入的内容。
* 可以直接输入字符串，也可以使用变量。

### 示例

在聊天输入框中输入文字：

```text
等待(2000)
输入("你好")
等待(1000)

按下enter
等待(200)
弹起enter
```

使用变量输入：

```text
str = "Hi 你吃饭了吗"
输入(str)
```

## 2. 极简输入弹窗

### 命令介绍

创建一个极简输入弹窗，用于让用户输入任意文本内容。

支持：

* 设置弹窗位置
* 设置弹窗宽度和高度
* 设置界面风格
* 按回车确定
* 按 ESC 取消
* 点击确定按钮确定
* 点击取消按钮取消
* 达到指定字符数量后自动完成
* 输入停止指定毫秒数后自动完成
* 两种自动完成条件可以分别开启，也可以同时开启
* 任意一个自动完成条件满足都会完成输入

### 语法

```text
极简输入弹窗(提示内容, X坐标, Y坐标, 宽度, 高度, 界面风格, 自动完成长度, 停止输入毫秒数)
```

### 参数

| 参数    | 说明          | 默认值  |
| ----- | ----------- | ---- |
| 第1个参数 | 提示内容        | 必填   |
| 第2个参数 | 弹窗 X 坐标     | 必填   |
| 第3个参数 | 弹窗 Y 坐标     | 必填   |
| 第4个参数 | 弹窗宽度        | 560  |
| 第5个参数 | 弹窗高度        | 325  |
| 第6个参数 | 界面风格        | 0    |
| 第7个参数 | 自动完成长度      | 0，关闭 |
| 第8个参数 | 停止输入自动完成毫秒数 | 0，关闭 |

### 界面风格

```text
0 = 极简白
1 = 云灰
2 = 雾蓝
3 = 深夜
4 = 暖沙
5 = 樱粉
6 = 深蓝
7 = 紫晶
8 = 橙阳
9 = 薄荷
10 = 青墨
11 = 玫瑰
```

### 示例

使用默认宽高和默认风格：

```text
极简输入弹窗("请输入用户名", 200, 300)
```

设置宽度和高度：

```text
极简输入弹窗("请输入内容", 200, 300, 700, 400)
```

使用第 5 种界面风格：

```text
极简输入弹窗("请输入内容", 200, 300, 560, 325, 5)
```

输入达到 12 个字符后自动完成：

```text
极简输入弹窗("请输入单号", 200, 300, 560, 325, 0, 12)
```

停止输入 100 毫秒后自动完成：

```text
极简输入弹窗("请输入单号", 200, 300, 560, 325, 0, 0, 100)
```

同时设置自动完成长度和停止输入时间：

```text
极简输入弹窗("请输入单号", 200, 300, 560, 325, 0, 12, 100)
```

## 4. 弹窗椭圆输入框

### 命令介绍

使用淡蓝色椭圆的弹窗输入框输入一段字符串。

### 语法

```text
弹窗椭圆输入框(提示内容, 是否置顶, 初始化字符串, x, y)
```

### 参数

* `提示内容`：输入框提示文字。
* `是否置顶`：是否置顶。
* `初始化字符串`：输入框初始显示的字符串。
* `x`：弹窗 X 坐标。
* `y`：弹窗 Y 坐标。

### 示例

```text
循环 0 小于 1
	str = 弹窗椭圆输入框("请输入", 1, "")
	
	fPos = 查找字符串位置(str, "exit")
	如果 fPos 不等于 -1
		显示("好的，退出")
		
		跳出循环
	否则
		显示("不是")
	如果完成
循环完成

显示("已退出")
```

## 5. 输入字母

### 命令介绍

将传递给命令中的字母转换为键值后按下。

### 语法

```text
输入字母(字母字符串)
```

也支持设置每按一个键后的等待时间：

```text
输入字母(字母字符串, 每个字母键延迟毫秒)
```

### 示例

```text
输入字母("hello")
等待(1000)
```

```text
输入字母("jintiantianqihenhao")
等待(1000)
```

使用变量：

```text
str = "hello"
输入字母(str)
等待(1000)
```

每按一个键后等待 100 毫秒：

```text
str = "hello"
输入字母(str, 100)
等待(1000)
```

## 6. 输入大小写字母

### 命令介绍

输入大小写字母。

遇到大写字母时会自动按 `CapLockS` 键。

### 语法

```text
输入大小写字母(要输入的字母, CAPLOCKS键按下的毫秒, 每一个字母键延迟毫秒)
```

### 参数

* `要输入的字母`：要输入的大小写字母。
* `CAPLOCKS键按下的毫秒`：切换大小写时 `CAPLOCKS` 键按下的时间。
* `每一个字母键延迟毫秒`：每个字母键之间的延迟时间。

### 示例

```text
倒计时显示("", 3, "秒后开始输入")
输入大小写字母("ABCabc71C", 200, 200)

按下enter
等待(200)
弹起enter
```

## 7. 输入文本字符串

### 命令介绍

读取文本文件内容，将文本内容通过弹窗复制到剪切板，然后使用 `Ctrl + V` 粘贴输入。

```text

```

3 个参数：

```text
输入文本字符串(文本路径, 窗口宽度, 窗口高度)
```

5 个参数：

```text
输入文本字符串(文本路径, 窗口宽度, 窗口高度, x坐标, y坐标)
```

### 示例

```text
path = "c:/下载/水果列表.txt"
输入文本字符串(path)
```

## 10. 输入字节字符串

### 命令介绍

输入字节字符串。

### 语法

```text
输入字节字符串(字节字符串)
```

### 示例

```text
输入字节字符串("13-10")
等待(1000)
```

结合大文本读取：

```text
path = "c:/下载/6.txt"

读取大文本("list", path)
length = 获取大文本长度("list")

i = 0
循环 i 小于 length
	str = 大文本中获取行转为字节字符串("list", i)
	println("第", i, "行的字节字符串: ", str)

	输入字节字符串(byteStr)
	输入字节字符串("13-10")
	等待(1000)

	i = i + 1
循环完成
```

> 注意：上面的教程示例中定义的是 `str`，后面实际传入的却是 `byteStr`。这里保留教程原始写法，不自行修改为猜测的正确变量名。

## 11. 输入网址字符串

### 命令介绍

输入网址字符串。

使用前需要先将输入法切换为英文。

### 语法

```text
输入网址字符串(网址, 按下Shift等待的毫秒, 间隔等待的毫秒)
```

### 参数

* `网址`：要输入的网址。
* `按下Shift等待的毫秒`：按下 Shift 后等待的时间。
* `间隔等待的毫秒`：输入字符之间的等待时间。

### 示例

```text
str = "https://www.baidu.com/3288329feiSFNI3INSk223"

等待(2000)
输入网址字符串(str, 100, 50)
```

# AI 生成注意事项

## 1. 不要混淆不同输入命令

这些命令虽然都与“输入”有关，但用途和参数不同：

* `输入`：模拟剪切板粘贴输入。
* `输入字母`：将字母转换为键值后按键。
* `输入大小写字母`：输入大小写字母，并处理大小写切换。
* `输入文本字符串`：读取文本文件后通过剪切板粘贴输入。
* `输入中文文本字符串`：读取 UTF-8 文本后输入。
* `输入网址字符串`：输入网址，需要先切换英文输入法。
* `input`：在控制台窗口输入内容。
* `键入`：输入指定字符串。

## 2. 不要自行增加参数

只有官方资料明确确认的参数形式才能生成。

例如已经确认：

```text
输入字母("hello", 100)
```

但不能因为其他命令存在类似参数，就自行推测：

```text
输入("hello", 100)
```

也是合法语法。

## 3. 字符串和变量都可以按照已确认的语法使用

例如：

```text
str = "hello"
输入字母(str)
```

## 4. 使用英文逗号

多个参数之间必须使用英文逗号：

```text
输入大小写字母("ABCabc", 200, 200)
```

不要使用中文逗号：

```text
输入大小写字母("ABCabc"，200，200)
```

## 5. 注意输入网址的前置条件

使用：

```text
输入网址字符串(...)
```

前需要先将输入法切换为英文。

## 6. 不要把教程说明文字当成代码

教程中的说明文字不代表楚河脚本支持行尾注释。

## 7. 示例中的疑似变量名错误不要擅自修改

如果官方教程中的示例存在变量名不一致等问题，应保留原始资料并明确指出问题，而不是在没有实现依据的情况下自行修改。
