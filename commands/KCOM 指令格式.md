# 楚河脚本：KCOM 指令格式

KCOM 是通过指定的十六进制数据包向 KCOM 设备发送键盘、鼠标等控制指令的功能。

---

## 使用前提

使用 KCOM 功能前，需要修改：

```text
C:\楚河脚本\配置目录\kcom端口波位宽高配置.txt
```

将文件中的**第一个数字改为 `1`**，才表示启用 KCOM。

---

# 1. kcom发送指令

### 功能

向 KCOM 发送指定的十六进制数据包。

参数使用十六进制字符串表示。

不同类型的 KCOM 操作，发送的数据包参数数量可能不同，应按照对应操作的实际数据包格式使用。

### 示例1：Ctrl + A

```text
kcom发送指令("57", "AB", "01", "01", "00", "04", "00", "00", "00", "00", "00")
```

### 松开按键

按键按下后必须发送释放指令，否则按键会一直处于按下状态。

```text
kcom发送指令("57", "AB", "01", "00", "00", "00", "00", "00", "00", "00", "00")
```

### 示例2：鼠标左键拖动

```text
等待(1000)

kcom发送指令("57", "AB", "04", "01", "2C", "0E", "55", "00", "00")

等待(100)

kcom发送指令("57", "AB", "04", "01", "63", "0D", "9C", "00", "00")

等待(100)

kcom发送指令("57", "AB", "04", "00", "63", "0D", "9C", "00", "00")

等待(500)
```

上述示例中：

1. 第一条指令按下鼠标左键并移动。
2. 第二条指令保持左键按下状态并继续移动。
3. 第三条指令释放鼠标左键。

# 2. kcom按键

### 功能

按下指定键，等待指定时间后弹起。

时间参数可以省略，默认等待 `100ms`。

### 语法

```text
kcom按键(按键名称, 等待毫秒数)
```

### 示例

```text
kcom按键("a", 100)

等待(1000)

kcom按键("b", 100)
```

# 7. kcomXyTo4

### 功能

将绝对坐标转换为 4 个十六进制数据包。

返回一个数组，结果保存在：

```text
list[0]
list[1]
list[2]
list[3]
```

这些数据可以直接用于 `kcom发送指令()` 的坐标数据参数。

### 语法

```text
kcomXyTo4(x, y)
```

### 示例

```text
list = kcomXyTo4(2270, 30)

i = 0
length = 获取数组长度(list)

循环 i 小于 length
	print(list[i], " ")

	i = i + 1
循环完成

println()
```

### 配合 kcom发送指令

例如将坐标转换后，让鼠标移动到指定位置：

```text
list = kcomXyTo4(2270, 30)

kcom发送指令("57", "AB", "04", "01", list[0], list[1], list[2], list[3], "00")
```

# 8. kcom组合按键

### 功能

执行组合键操作。

### 语法

```text
kcom组合按键(按键1, 按键2, 等待毫秒数)
```

### 示例

```text
kcom组合按键("alt", "tab", 100)

等待(500)

i = 0
循环 i 小于 5
	println("第", i, "次tab")

	kcom组合按键("alt", "tab", 100)

	等待(300)

	i = i + 1
循环完成

kcom键盘弹起()

println("脚本结束")
```

# 9. kcom键盘按下

### 功能

按下指定键，但不会自动弹起。

需要配合 `kcom键盘弹起()` 使用。

### 语法

```text
kcom键盘按下(按键名称)
```

### 示例

```text
kcom键盘按下("f")

等待(3000)

kcom键盘弹起()
```

---

# 10. kcom键盘弹起

### 功能

弹起所有按键。

发送全 0 数据包，以释放当前所有处于按下状态的键。

### 语法

```text
kcom键盘弹起()
```

### 示例

```text
kcom键盘按下("shift")

等待(1000)

kcom键盘弹起()
```

---

# 11. kcom鼠标左键按下

### 功能

按下鼠标左键但不立即弹起。

需要配合 `kcom鼠标左键弹起()` 使用，可以实现持续按住鼠标左键的效果。

### 语法

```text
kcom鼠标左键按下()
```

### 示例

```text
kcom鼠标移动(500, 300)

kcom鼠标左键按下()

等待(2000)

kcom鼠标左键弹起()
```

# 13. 使用模块实现双击

教程中的 `双击()` 并不是这里额外定义的 KCOM 内置命令，而是通过 `做个模块` 自行创建的模块。

### 示例

```text
双击(2270, 30)

做个模块 双击(x, y)
	list = kcomXyTo4(x, y)

	kcom发送指令("57", "AB", "04", "01", list[0], list[1], list[2], list[3], "00")
	等待(5)

	kcom发送指令("57", "AB", "04", "00", list[0], list[1], list[2], list[3], "00")
	等待(5)

	kcom发送指令("57", "AB", "04", "01", list[0], list[1], list[2], list[3], "00")
	等待(5)

	kcom发送指令("57", "AB", "04", "00", list[0], list[1], list[2], list[3], "00")
	等待(100)
模块完成
```

其基本原理是：

```text
鼠标左键按下
→ 等待
→ 鼠标左键弹起
→ 等待
→ 鼠标左键按下
→ 等待
→ 鼠标左键弹起
```

# AI 使用注意事项

1. 使用 KCOM 功能前，必须确认 `C:\楚河脚本\配置目录\kcom端口波位宽高配置.txt` 的第一个数字已经设置为 `1`。
2. `kcom发送指令()` 的参数是十六进制字符串。
3. KCOM 键盘按下后必须注意释放，否则按键可能保持按下状态。
4. `kcom键盘按下()` 不会自动弹起，需要配合 `kcom键盘弹起()`。
5. `kcom鼠标左键按下()` 不会自动弹起，需要配合 `kcom鼠标左键弹起()`。
6. `kcomXyTo4()` 用于把普通绝对坐标转换为 KCOM 所需的 4 个十六进制坐标数据。
7. `kcom组合按键()` 用于组合键操作。
8. 教程中的 `双击()` 是使用 `做个模块` 自行定义的模块，不应视为独立的 KCOM 内置命令。
9. 不要根据其他 KCOM、键盘协议或鼠标协议自行推测数据包中每一个十六进制字节的具体含义；本文件只记录已经确认的调用方式和示例。
10. KCOM 数据包的具体参数数量会根据指令类型不同而变化，应以对应的实际数据包格式为准。
