# 楚河脚本语言规则

## 编程语言名

**楚河**

---

# 一、基本语言规则

## 1. 每一行只能写一条语句

楚河语言每一行只能写一条语句。

例如：

```text
i = 0
i = i + 1
```

不支持一行写多个语句。

---

## 2. 不支持嵌套函数调用

不支持多重嵌套括号。

例如不支持：

```text
函数名(函数名(参数1, 参数2))
```

应该先把函数调用的结果保存到变量中，再进行下一次函数调用。

---

# 二、变量赋值

## 1. 支持的变量赋值

支持：

```text
str = ""
i = 0
i = i + 1
```

## 2. 不支持的变量赋值

不支持：

```text
i++
str3 = str1 + str2
```

## 3. 变量必须定义或者初始化后才能使用

例如：

```text
i = 0
```

这就等于是定义了变量并赋值。

---

# 三、循环语法

## 1. 无限循环

支持：

```text
循环 0 小于 1
	// 中间放要循环的语句
循环完成
```

## 2. 普通循环

支持：

```text
i = 0
循环 i 小于 9
	// 中间放要循环的语句
	i = i + 1
循环完成
```

## 3. 继续循环

```text
继续循环
```

等同于 `continue`。

## 4. 跳出循环

```text
跳出循环
```

等同于 `break`。

## 5. 循环条件只能判断整数

循环语句只可以用来判断整数值，不可以用来判断字符串。

只支持：

```text
循环 整数 小于 整数
循环 整数 大于 整数
```

也就是说，小于、等于、大于、不等于、小于等于、大于等于等比较符号的两边，都只支持使用整数。

不支持字符串。

不支持函数调用。

## 6. 循环条件同行不支持调用函数

循环条件的同行里不支持调用函数。

例如不支持：

```text
循环 获取数组长度(list) 小于 10
	// 错误
循环完成
```

应该先调用函数，将结果保存到变量：

```text
listLength = 获取数组长度(list)

i = 0
循环 i 小于 listLength
	// 中间放要循环的语句
	i = i + 1
循环完成
```

注意：

**循环块内部可以调用函数。**

## 7. 单条循环语句不支持多个逻辑判断

不支持：

**与、或、非的一条语句里写多个逻辑判断。**

例如不支持：

```text
循环 i 小于 10 并且 result 等于 是
	// 错误
循环完成
```

# 四、函数调用

## 1. 一行只能写一条语句

函数调用也必须遵守一行只能写一条语句的规则。

## 2. 不支持多重嵌套括号

例如不支持：

```text
函数名(函数名(参数1, 参数2))
```

## 3. 函数参数必须使用英文逗号分隔

例如：

```text
拼接字符串("hello", "world")
```

参数必须使用英文半角逗号 `,` 分隔。

---

# 五、数组定义

## 1. 支持数组定义

支持：

```text
list[0] = ""
list[1] = ""
list = 读取文本(txtPath)
```

## 2. 不支持的数组定义

不支持：

```text
list[] = {"", ""}
```

**不支持定义空数组！**

---

# 六、数组名不能和普通变量重名

数组名不能和普通变量重名。

例如已经有了：

```text
index[0] = "707, 580"
index[1] = "800, 600"
```

这样的数组，那么就不要再写：

```text
index = length - 1
```

这种把 `index` 当普通变量使用的语句。

## 错误示例

```text
index[0] = "707, 580"
color[0] = "EFD1DA"
resultList = bi坐标找色多位置("bi", 0, 0, 0, 0, 20, 20, 0, 10, 10, 10, index, color)
index = length - 1
```

下一轮循环再调用：

```text
bi坐标找色多位置(..., index, color)
```

此时 `index` 已经变成普通变量，命令找不到数组，会静默失败，返回数组长度一直为 `0`，没有任何报错。

## 正确写法

数组名和普通变量名必须使用不同的名字。

例如把下标变量改名为 `lastIndex`：

```text
lastIndex = length - 1
```

同理：

传给命令的数组名，例如：

```text
index
color
```

以及返回数组名，都不要再当作普通变量赋值。

# 七、数组赋值

支持：

```text
list2[0] = list[0]
list2[1] = list[1]
list2[2] = "hello"
```

不支持：

```text
arr[i+1] = 3
```

只支持先计算下标，再使用变量：

```text
i2 = i + 1
arr[i2] = 3
```

也就是说：

**数组下标中不能直接写计算表达式。**

---

# 八、逻辑判断

## 1. 支持的判断

支持：

```text
等于
小于
大于
不等于
小于等于
大于等于
```

## 2. 或者

`或者` 相当于 `||`。

## 3. 并且

`并且` 相当于 `&&`。

例如：

```text
如果 result 等于 是 并且 result2 等于 否
否则
如果完成
```

## 4. 如果语法

```text
如果 i 小于 3
	// 中间放要执行的语句
否则
	// 中间放要执行的语句
如果完成
```

## 5. 如果、否则、如果完成必须一起使用

必须：

```text
如果
否则
如果完成
```

一起使用。

就算是没有否则语句，也必须带上 `否则` 块。

**千万不可以因为没有否则语句，就不写否则关键字。**

例如：

```text
如果 cmpResult 等于 是
	println("空字符串")
否则
	
如果完成
```

## 6. 如果语句只可以判断整数、是、否

如果语句只可以用来判断：

- 整数
- 是
- 否

## 7. 判断字符串是否为空

需要判断字符串是否为空时，应该使用“对比字符串”命令。

例如：

```text
cmpResult = 对比字符串(result, "")

如果 cmpResult 等于 是
	println("空字符串")
否则
	
如果完成
```

## 8. 判断是否包含字符串

判断是否包含字符串，需要通过“查找字符串位置”命令。

例如：

```text
pos = 查找字符串位置(result, "变化")

如果 pos 大于 -1
	println("包含变化这个词")
否则
	
如果完成
```

## 9. 如果条件同行不支持函数调用

如果条件的同行里不支持函数调用。

例如不支持：

```text
如果 获取数组长度(list) 大于 0
	println("有内容")
否则
	
如果完成
```

应该先调用函数：

```text
listLength = 获取数组长度(list)

如果 listLength 大于 0
	println("有内容")
否则
	
如果完成
```

**如果块内可以调用函数。**

## 10. 不支持如果-否则如果-否则-如果完成

不支持：

```text
如果
否则
如果
否则
如果完成
```

也就是不支持：

```text
如果-否则如果-否则-如果完成
```

# 九、缩进格式

不管是循环，还是如果语句，下一行语句的缩进格式全部使用 `\t`，而不是空格！

正确：

```text
循环 0 小于 1
	显示("正在循环")
循环完成
```

这里的缩进必须使用：

**Tab**

而不是空格。

---

# 十、注释

## 1. 单行注释

只支持单行开头用 `//` 进行注释。

例如：

```text
// 这是注释
println("hello")
```

## 2. 块注释

也支持块注释：

```text
/*
这是块注释
*/
```

但是：

```text
/*
```

和：

```text
*/
```

必须各自单独占一行。

例如：

```text
/*

这是块注释

*/
```

## 3. 绝不可以在语句的同一行末尾加注释

错误：

```text
读取文本(path) // 错误！
```

错误：

```text
读取文本(path) /* 错误！
```

## 4. 注释格式建议

建议：

**注释块的上下各留一个空行。**

保持代码可读性。

同时建议：

**在每行注释的上一行都用一个空行。**

# 十二、变量默认的基本类型

变量默认的基本类型为**字符串**。

也就是说：

```text
i = 0
str = 拼接字符串("你好", i)
```

这里 `i` 不用转换为字符串。

但是如果要从字符串到数字计算，最好还是先转换为整数：

```text
numberStr = "33"
number = 转换为整数(numberStr)
i = 5 + number
println("i的值是：", i)
```

# 十三、模块（函数）用法

## 1. 在文件底部使用模块

支持：

```text
做个模块 模块名()
	// 代码
模块完成
```

## 2. 在一个新文件里做模块（推荐）

推荐在一个新文件里做个模块。

例如：

```text
模块1.txt
```

内容：

```text
做个模块 模块名(参数1, 参数2)
	// 代码
	模块名 = 返回值
模块完成
```

调用时：

```text
安装模块("c:/楚河脚本/模块目录/模块1.txt")
```

然后即可调用：

```text
返回值 = 模块名()
```

## 3. 模块用途

模块一般用于返回一个值，也可以返回数组。

## 4. 模块参数

模块支持传递：

- LortImage 的 lg 对象
- bi 对象
- 数组传参

数组需要用数组名和 `[]` 符号。

例如：

```text
list[0] = "hello"
list[1] = "world"

dolist(list[])
```

模块中：

```text
做个模块 dolist(list)
	i = 0
	listLength = 获取数组长度(list)
	循环 i 小于 listLength
		println(list[i], " ")
		i = i + 1
	循环完成
	println()
模块完成
```

# 十六、运行一个脚本文件并拷贝变量

如果需要将父脚本变量传递到子脚本，可以使用：

```text
运行一个脚本文件并拷贝变量(脚本文件路径)
```

作用：

在当前脚本中调用另一个脚本文件，并将当前脚本的所有变量深拷贝一份传入子脚本。

子脚本可以直接使用父脚本中的所有变量。

但是：

**子脚本对变量的任何修改都不会影响父脚本。**

## 1. 变量传递方向

变量是单向传递的：

```text
父脚本 -> 子脚本
```

## 2. 使用方法

```text
运行一个脚本文件并拷贝变量("c:/楚河脚本/脚本目录/02.txt")
```

## 3. 示例

### 01

```text
a = 3
b = 4

list[0] = 1
list[1] = 2
list[2] = "python"

运行一个脚本文件并拷贝变量("c:/楚河脚本/脚本目录/02.txt")

println("01里面的代码a的值是: ", a, "，b的值是: ", b)
```

### 02

```text
println("我是02")
println("a的值是: ", a, "，b的值是: ", b)
a = 0
b = 1
println("02修改后a的值是: ", a, "，b的值是: ", b)

println("显示变量列表")

i = 0
listLength = 获取数组长度(list)
循环 i 小于 listLength
	println(list[i])
	i = i + 1
循环完成
println()
```

所以建议：

如果是 `01` 里面要调用 `02`，并且要将变量传给 `02`，那么就使用：

```text
运行一个脚本文件并拷贝变量(脚本绝对路径)
```

# 十八、数组类命令的参数写法

以下已经实测确认：

```text
获取数组长度
清空数组元素
数组转大文本数组
```

这些命令的第 1 个参数如果是数组名：

**数组名都不带双引号。**

例如：

```text
获取数组长度(list)
清空数组元素(list, mylist)
数组转大文本数组(list, "newList")
```

错误：

```text
获取数组长度("list")
```

带双引号会导致数组名匹配失败。

可能出现：

- 长度返回 0
- 清空不生效
- 没有报错

`FunctionArrCommand` 中数组名匹配已改为：

**变量名以 `数组名[` 开头**

这样不再把：

```text
mylist[0]
```

误算进：

```text
list
```

的长度。

```text
i++
```

正确：

```text
i = i + 1
```

## 5. 使用 str1 + str2 拼接字符串

错误：

```text
str3 = str1 + str2
```

应该使用：

```text
str3 = 拼接字符串(str1, str2)
```

## 6. 数组名和普通变量名重复

错误：

```text
index[0] = "707, 580"
index[1] = "800, 600"

index = length - 1
```

正确：

```text
lastIndex = length - 1
```

数组名和普通变量名必须保持不同。

# 二十、生成楚河脚本时必须遵守的核心规则

1. 每一行只能写一条语句。
2. 不支持嵌套函数调用。
3. 变量必须先定义或者初始化。
4. 循环条件只能使用整数进行判断。
5. 循环条件同行不支持函数调用。
6. 如果条件同行不支持函数调用。
7. 循环块内部可以调用函数。
8. 如果块内部可以调用函数。
9. 不支持一条循环语句里写多个逻辑判断。
10. 不支持一条判断语句里写多个不符合规则的逻辑判断。
11. 数组名不能和普通变量重名。
12. 数组下标不能直接写 `i+1` 这样的计算表达式。
13. 计算数组下标时，应先保存到变量。
14. `如果`、`否则`、`如果完成` 必须一起使用。
15. 不支持 `如果-否则如果-否则-如果完成`。
16. 缩进必须使用 Tab，也就是 `\t`。
17. 不可以使用空格代替 Tab 缩进。
18. 单行注释只能在行开头使用 `//`。
19. `/*` 和 `*/` 必须各自独占一行。
20. 不可以在语句同行末尾添加注释。
21. 字符串是否相同使用“对比字符串”命令。
22. 判断字符串是否包含内容使用“查找字符串位置”命令。
23. 数组类命令的数组名通常不带双引号。
24. 数组传参使用数组名和 `[]`，例如 `list[]`。
25. 变量默认的基本类型为字符串。
26. 字符串参与数字计算时，最好先转换为整数。
27. 模块可以放在当前文件底部。
28. 推荐将模块单独放在新文件中。
29. 模块支持返回值，也可以返回数组。
30. 模块支持传递 LortImage 的 lg 对象、bi 对象和数组。
31. 脚本文件之间的普通变量默认隔离。
32. `运行一个脚本文件` 支持传入参数和返回值。
33. `运行一个脚本文件并拷贝变量` 可以将父脚本变量深拷贝到子脚本。
34. 父脚本与子脚本的变量传递方向为：父脚本 -> 子脚本。
35. 全局变量命令支持内存共享，但不支持数组。
