# 楚河脚本循环命令

本文档记录楚河脚本中已经确认的循环相关语法。

---

## 1. 循环

### 命令介绍

`循环` 用于重复执行一段代码。

循环结构：

```text
循环 条件
	循环中的代码
循环完成
```

循环条件成立时，会执行循环块中的代码。

### 无限循环

使用：

```text
循环 0 小于 1
	要无限重复执行的代码
循环完成
```

可以形成无限循环。

只要条件一直成立，循环就会持续运行，直到脚本被停止、退出，或者使用 `跳出循环` 离开循环。

### 示例：鼠标一直移动到左上角

```text
循环 0 小于 1
	显示("鼠标一直在左上角，可以按F10停止脚本")
	鼠标移动(0, 0)
	等待(1000)
循环完成
```

### 示例：无限循环移动鼠标

```text
循环 0 小于 1
	显示("鼠标第1次移动")
	鼠标移动(0, 0)
	等待(1000)
	显示("鼠标第2次移动")
	鼠标移动(100, 100)
	等待(1000)
	显示("鼠标第3次移动")
	鼠标移动(200, 200)
	等待(1000)
循环完成
```

### 示例：无限循环按键

```text
循环 0 小于 1
	按下b
	等待(200)
	弹起b
循环完成
```

## 2. 循环完成

`循环完成` 表示循环代码块的结束。

每个 `循环` 都必须有对应的 `循环完成`。

示例：

```text
a = 0
循环 a 小于 3
	鼠标移动(0, 0)
	等待(1000)
	a = a + 1
循环完成
```

---

## 3. 使用变量控制循环次数

可以通过整数变量控制循环执行次数。

### 循环3次

```text
a = 0
循环 a 小于 3
	鼠标移动(0, 0)
	等待(1000)
	a = a + 1
循环完成
```

### 循环100次

```text
a = 0
循环 a 小于 100
	鼠标移动(0, 0)
	等待(1000)
	a = a + 1
循环完成
```

### 循环9999次

```text
a = 0
循环 a 小于 9999
	鼠标移动(0, 0)
	等待(1000)
	a = a + 1
循环完成
```

楚河脚本不使用其他编程语言常见的：

```text
a++
```

而是使用：

```text
a = a + 1
```

## 4. 循环中显示循环次数

```text
i = 0
循环 i 小于 10
	显示(i)
	等待(1000)
	i = i + 1
循环完成
```

## 5. 循环中生成循环次数提示语

```text
提示语前半段 = "这是循环的第"
提示语后半段 = "次"
提示语 = ""

i = 0
k = 1
循环 i 小于 10
	提示语 = 拼接字符串(提示语前半段, k, 提示语后半段)
	显示(提示语)
	等待(1000)

	i = i + 1
	k = k + 1
循环完成
```

这里：

* `i` 用于控制循环次数。
* `k` 用于显示当前循环次数。

---

## 6. 跳出循环

### 命令介绍

`跳出循环` 用于立即结束当前循环。

通常可以配合 `如果` 使用，在满足指定条件时提前结束循环。

### 示例

循环10次，在第6次停止：

```text
提示语前半段 = "这是循环的第"
提示语后半段 = "次"
提示语 = ""

i = 0
k = 1
循环 i 小于 10
	提示语 = 拼接字符串(提示语前半段, k, 提示语后半段)
	显示(提示语)
	等待(1000)

	i = i + 1

	如果 i 等于 6
		显示("第6次已经到了，不再继续循环了，到此为止")
		等待(3000)
		跳出循环
	否则
	如果完成

	k = k + 1
循环完成
```

`跳出循环` 执行后，会立即离开当前循环。

## 7. 标记

`标记` 用于在代码中标记一个位置。

语法：

```text
标记 标记名称
```

示例：

```text
标记 到这里来
```

---

## 8. 跳到标记

`跳到标记` 用于直接跳到指定的 `标记` 位置继续运行。

语法：

```text
跳到标记 标记名称
```

示例：

```text
i = 0
循环 i 小于 100

	显示("i的值是: ", i)
	等待(100)

	如果 i 等于 2
		跳到标记 到这里来
	否则
	如果完成

	i = i + 1
循环完成

标记 到这里来
如果 i 小于 90
	显示("i的值是: ", i)
	等待(100)
否则
	显示("i的值是: ", i)
	等待(100)
如果完成
```

当 `i` 等于 `2` 时，会直接跳到：

```text
标记 到这里来
```

因此不会继续执行：

```text
i = i + 1
```

此时 `i` 的值保持为 `2`。

## 9. 循环与如果配合使用

`循环` 内部可以使用 `如果` 判断条件，并通过 `跳出循环` 提前结束循环。

例如：

```text
循环 条件
	如果 判断条件
		...
		跳出循环
	否则
		...
	如果完成

	...
循环完成
```

### 注意

楚河脚本的 `如果` 结构必须完整包含：

```text
如果
否则
如果完成
```

即使 `否则` 分支没有实际代码，也必须保留 `否则`。

例如：

```text
如果 i 等于 6
	跳出循环
否则
如果完成
```

---

## 10. 嵌套循环中的如果

循环内部可以使用嵌套的 `如果`。

例如判断鼠标是否位于屏幕左上角：

```text
横轴坐标 = 0
纵轴坐标 = 0

循环 0 小于 1
	鼠标位置 = 获取鼠标位置()
	横轴坐标 = x(鼠标位置)
	纵轴坐标 = y(鼠标位置)

	如果 横轴坐标 等于 0
		如果 纵轴坐标 等于 0
			打开文件("c:/windows/system32/calc.exe")
			跳出循环
		否则
			显示(鼠标位置)
		如果完成
	否则
		显示(鼠标位置)
	如果完成
循环完成
```
