# 楚河脚本图色命令

本文档记录楚河脚本中已经确认的图像、颜色、坐标找色、BufferedImage（`bi`）、LortImage（`lg`）以及模板找图相关命令。

这些命令主要用于：

* 屏幕截图
* 图片读取与保存
* 单点找色、多点找色
* 坐标找色
* 多位置找色
* 图片模板匹配
* 多尺度模板匹配
* 图像比较
* 像素差异统计
* 灰度化
* 二值化
* 像素范围颜色处理
* 连通像素块分析
* 图片文件夹批量查找
* LortImage 颜色统计
* BufferedImage 像素颜色读取

---

## 一、重要规则

### 1. `bi` 与 `LortImage` 是不同的图像对象

以下两套命令不能混用：

* `bi`：BufferedImage 图像对象
* `LortImage`：LortImage 图像对象

例如：

```text
读取屏幕到bi("big", 0, 0, 0, 0)
```

与：

```text
读取屏幕到LortImage("lg", 0, 0, 0, 0)
```

分别创建不同类型的图像对象。

---

### 2. 坐标通常是图像局部坐标

涉及 `bi` 的找图、找色命令时，返回坐标通常是当前 `bi` 图像内部的局部坐标，而不是自动转换后的屏幕绝对坐标。

---

### 3. 未找到通常返回 `-1, -1`

部分返回坐标的命令在没有找到目标时返回：

```text
-1, -1
```

可以使用：

```text
坐标x = x(结果坐标)
坐标y = y(结果坐标)
```

然后判断：

```text
如果 坐标x 等于 -1
	显示("没找到")
否则
	显示("找到了")
如果完成
```

---

### 4. 数组结果使用 `获取数组长度`

例如：

```text
listLength = 获取数组长度(list)

i = 0
循环 i 小于 listLength
	println(list[i])
	i = i + 1
循环完成
```

# 二、LortImage 命令

## 1. 读取屏幕到LortImage

### 语法

```text
读取屏幕到LortImage("LortImage对象名", startX, startY, endX, endY)
```

### 功能

读取屏幕指定区域到 LortImage 对象。

如果范围全部为 `0`，表示读取整个屏幕。

### 示例

```text
读取屏幕到LortImage("lg", 90, 360, 189, 464)
```

---

## 2. LortImage转灰度

### 语法

```text
LortImage转灰度("源LortImage对象名", "目标LortImage对象名")
```

### 功能

将 LortImage 转换为灰度图，并保存到新的 LortImage 对象。

原对象不会被修改。

### 示例

```text
读取屏幕到LortImage("lg", 90, 360, 189, 464)
LortImage转灰度("lg", "grayLg")

LortImageWriteImage("grayLg", "c:/楚河脚本/资源目录/临时图.png")
打开取色器("c:/楚河脚本/资源目录/临时图.png", 1200, 800)
```

---

## 3. LortImage二值化

### 语法

```text
LortImage二值化("源LortImage对象名", "目标LortImage对象名", threshold)
```

### 参数

* 第1个参数：源 LortImage 对象
* 第2个参数：目标 LortImage 对象
* 第3个参数：二值化阈值

### 示例

```text
读取屏幕到LortImage("lg", 90, 360, 189, 464)
LortImage转灰度("lg", "grayLg")
LortImage二值化("grayLg", "binaryLg", 180)

LortImageWriteImage("binaryLg", "c:/楚河脚本/资源目录/临时图.png")
```

---

## 4. LortImage区域内获取指定颜色数量

### 语法

```text
LortImage区域内获取指定颜色数量(LortImage对象名, startX, startY, endX, endY, 颜色值)
LortImage区域内获取指定颜色数量(LortImage对象名, startX, startY, endX, endY, 颜色值, rRange, gRange, bRange)
```

### 功能

统计指定 LortImage 区域内符合目标颜色的像素数量。

### 参数

1. LortImage 对象名
2. 区域起始 X
3. 区域起始 Y
4. 区域结束 X
5. 区域结束 Y
6. 目标 16 进制颜色值
7. RGB 允许偏差 R，可选
8. RGB 允许偏差 G，可选
9. RGB 允许偏差 B，可选

不填写 RGB 偏差时进行精确匹配。

填写 RGB 偏差后按照 RGB 范围进行匹配。

### 返回值

返回符合条件的像素数量。

### 示例

```text
读取屏幕到LortImage("lg", 0, 0, 1920, 1080)

number1 = LortImage区域内获取指定颜色数量("lg", 100, 100, 500, 500, "C8C8C8")
显示("精确匹配数量: ", number1)
等待(500)

number2 = LortImage区域内获取指定颜色数量("lg", 100, 100, 500, 500, "C8C8C8", 10, 10, 10)
显示("带偏色匹配数量: ", number2)
等待(500)
```

## 5. LortImage读取像素范围重设颜色值

### 语法

```text
LortImage读取像素范围重设颜色值(源LortImage对象名, rMin, rMax, gMin, gMax, bMin, bMax, 范围内重设颜色, 范围外重设颜色, 结果LortImage对象名)
```

### 功能

遍历 LortImage 中的像素。

符合 RGB 指定范围的像素设置为指定颜色，不符合范围的像素设置为另一种颜色。

结果保存到新的 LortImage 对象。

### 示例

```text
读取屏幕到LortImage("lg", 0, 0, 1920, 1080)

LortImage读取像素范围重设颜色值("lg", 194, 252, 255, 255, 189, 235, "FFFFFF", "000000", "lg2")
```

## 6. LortImage查找像素块

### 语法

```text
LortImage查找像素块(LortImage对象名, 目标颜色, 阈值, 合并距离)
```

### 功能

在 LortImage 中查找指定颜色的连通像素块。

可以：

* 过滤像素数量过少的小块
* 合并距离较近的像素块

### 参数

* 第1个参数：LortImage 对象名
* 第2个参数：目标颜色
* 第3个参数：像素数量阈值
* 第4个参数：合并距离

### 返回值

返回数组。

每个元素格式为：

```text
块大小开始{像素数量}块大小结束坐标开始{中心x}, {中心y}坐标结束
```

### 示例

```text
读取屏幕到LortImage("lg", 0, 0, 1920, 1080)
LortImage读取像素范围重设颜色值("lg", 194, 252, 255, 255, 189, 235, "FFFFFF", "000000", "lg2")

list = LortImage查找像素块("lg2", "FFFFFF", 30, 50)
println("找到的像素块数量: ", list数组长度)
```

## 10. 清空bi

### 语法

```text
清空bi()
```

### 功能

清空当前脚本中所有已经载入的 `bi` 对象并释放内存。

适合在不再需要图像数据时主动释放内存。

### 示例

```text
读取图片到bi("small", "c:/楚河脚本/资源目录/目标图片.png")
读取屏幕到bi("big", 0, 0, 0, 0)

结果坐标 = bi找图("big", "small", 0, 0, 0, 0, 10, 10, 10)

坐标x = x(结果坐标)
坐标y = y(结果坐标)

如果 坐标x 等于 -1
	显示("没找到")
	等待(1000)
否则
	显示("找到了，坐标是: ", 结果坐标)
	等待(1000)
如果完成

清空bi()
显示("所有bi对象已清空")
等待(1000)
```

### 注意

此命令清空的是当前脚本本地的 `bi` 对象。

# 四、bi图像比较

## 11. bi比图

### 语法

```text
bi比图("bi名1", "bi名2")
bi比图("bi名1", "bi名2", rRange, gRange, bRange)
```

### 功能

比较两个 `bi` 对象的所有像素是否匹配。

两张图尺寸不同时直接返回 `否`。

### 返回值

返回：

```text
是
```

或：

```text
否
```

### 参数

RGB 容差参数可选。

不传时默认为精确比较。

### 示例

```text
读取屏幕到bi("bi1", 100, 100, 500, 500)

等待(2000)

读取屏幕到bi("bi2", 100, 100, 500, 500)

result = bi比图("bi1", "bi2", 10, 10, 10)

如果 result 等于 是
	显示("两张图一样，区域没有变化")
	等待(1000)
否则
	显示("两张图不一样，区域发生了变化")
	等待(1000)
如果完成
```

---

# 七、bi坐标找色

## 21. bi坐标找色

### 语法

```text
bi坐标找色("bi名", leftX, leftY, rightX, rightY, rRange, gRange, bRange, index, color)
```

### 功能

在 `bi` 指定范围内执行坐标找色。

采用：

**中心点 + 多偏移点颜色容差匹配**

的方式定位目标坐标。

搜索范围全部为 `0` 时表示全图查找。

### 坐标找色数据

数据来自两个数组：

* `index`
* `color`

数组第 `0` 个元素为中心点。

从第 `1` 个元素开始为偏移点。

### 示例

```text
index[0] = "960, 540"
color[0] = "FF0000"

index[1] = "970, 540"
color[1] = "FF1010"

index[2] = "960, 550"
color[2] = "FE0000"

读取屏幕到bi("big", 0, 0, 0, 0)
```

# 十、多尺度模板找图

## 28. 模板找图bi

### 功能

使用 OpenCV 多尺度模板匹配，在大图 `bi` 中查找小图 `bi`。

主要用于解决不同设备 DPI 缩放导致的模板大小不一致问题。

### 语法

```text
模板找图bi("大图bi名", "小图bi名")
```

```text
模板找图bi("大图bi名", "小图bi名", 缩放最小比例, 缩放最大比例, 缩放步长)
```

```text
模板找图bi("大图bi名", "小图bi名", 缩放最小比例, 缩放最大比例, 缩放步长, 匹配阈值)
```

### 默认参数

* 缩放最小比例：`0.5`
* 缩放最大比例：`2.0`
* 缩放步长：`0.1`
* 匹配阈值：`0.4`

### 返回值

返回字符串：

```text
x, y|匹配得分|最佳缩放比例
```

找到时例如：

```text
632, 848|0.729|1.2
```

未找到：

```text
-1, -1|0.000|0.0
```

### 匹配阈值

匹配阈值范围：

```text
0~1
```

低于阈值时认为没有找到。

调试时可以先使用较低阈值观察正确识别和误识别的得分差距，再确定最终阈值。

### 示例

```text
读取图片到bi("small", "c:/楚河脚本/资源目录/目标图片.png")

读取屏幕到bi("big", 0, 0, 0, 0)

result = 模板找图bi("big", "small")

坐标字符串 = 截取字符串(result, 0, 查找字符串位置(result, "|"))
坐标x = 转换为整数(截取字符串(坐标字符串, 0, 查找字符串位置(坐标字符串, ", ")))

如果 坐标x 等于 -1
	显示("没找到")
	等待(1000)
否则
	显示("找到了，结果是: ", result)
	等待(1000)
如果完成

result2 = 模板找图bi("big", "small", 0.8, 1.5, 0.1, 0.6)

显示("自定义参数结果: ", result2)
等待(1000)
```

```text
比图zcfbi("bi名1", "bi名2", 二值化阈值, 最小变化占比, 是否开启模糊降噪, 是否开启形态学膨胀)
```

### 参数

1. 第1个参数：bi对象名
2. 第2个参数：bi对象名
3. 二值化阈值，范围 `0~255`，推荐 `15~30`
4. 最小变化占比，范围 `0.0~1.0`，例如 `0.01` 表示 `1%`
5. 是否开启模糊降噪，可选，默认 `0`
6. 是否开启形态学膨胀，可选，默认 `0`

摄像头场景可以使用模糊降噪。

需要完整 bounding box 时可以开启形态学膨胀。

### 返回值

返回字符串：

```text
是否变化|变化像素数|变化占比|boundingBox
```

例如：

```text
是|3542|0.0141|120, 200, 350, 480
```

表示检测到变化。

无变化例如：

```text
否|0|0.0000|-1, -1, -1, -1
```

### 示例

```text
result = 比图zcfbi("bi1", "bi2", 20, 0.01)

result = 比图zcfbi("bi1", "bi2", 25, 0.01, 1, 0)
```

# 十五、轮廓找图

## 37. 轮廓找图bi

### 语法

```text
轮廓找图bi("大图BufferedImage对象名", "小图BufferedImage对象名")
```

或者：

```text
轮廓找图bi("大图BufferedImage对象名", "小图BufferedImage对象名", 匹配阈值)
```

### 功能

基于轮廓形状匹配进行找图。

主要根据图形的形状结构进行匹配，不依赖具体颜色。

可用于：

* 颜色主题变化
* 不同 DPI 缩放
* 图标颜色变化
* 图标大小变化

### 返回值

返回：

```text
x, y|得分|1.0
```

未找到：

```text
-1, -1|999.000|0.0
```

### 得分规则

该命令的得分与 `模板找图bi` 不同。

**得分越小表示越相似。**

参考范围：

* `0.00~0.05`：几乎完全一致
* `0.05~0.15`：较高置信匹配
* `0.15` 以上：形状差异较大

### 匹配阈值

默认：

```text
0.10
```

越小越严格。

* 漏识别时可以调大
* 误识别时可以调小
* 建议范围 `0.05~0.15`

### 示例

```text
读取屏幕到bi("bi1", 0, 0, 0, 0)

path = "c:/楚河脚本/资源目录/复制图标.png"
读取图片到bi("bi2", path)

resStr = 轮廓找图bi("bi1", "bi2", 0.10)

arr = 字符串分割(resStr, "|")
xy = arr[0]
score = arr[1]

println("坐标: ", xy)
println("得分: ", score)

cmpResult = 对比字符串(xy, "-1, -1")

如果 cmpResult 等于 否
	println("找到了")
否则
	println("没找到")
如果完成
```

# 十六、图像找图命令区别

目前已经确认的几种主要 `bi` 找图方式：

| 命令                          | 主要用途        | 返回         |
| --------------------------- | ----------- | ---------- |
| `bi找图`                      | 普通图片匹配      | 坐标         |
| `bi找图并容错`                   | 允许一定像素不匹配   | 坐标         |
| `bi找模糊图`                    | 按匹配阈值进行模糊查找 | 坐标         |
| `模板找图bi`                    | 多尺度模板匹配     | 坐标+得分+缩放比例 |
| `模板找图bi多位置`                 | 多尺度多位置匹配    | 数组         |
| `轮廓找图bi`                    | 基于轮廓形状匹配    | 坐标+得分      |
| `bi找文件夹里所有图`                | 文件夹候选图片快速查找 | 坐标         |
| `bi找文件夹里所有图_返回文件名`          | 文件夹候选图片查找   | 文件名        |
| `bi找文件夹里所有图_返回文件名和坐标`       | 文件名+坐标      | 数组         |
| `bi找文件夹里所有图多位置_返回文件名和数量和坐标` | 多位置统计       | 数组         |

这些命令虽然都属于“找图”，但参数形式、匹配方式和返回值不同。

AI 不应因为名称相似而自行认为它们可以互换。

# 十七、AI 生成楚河脚本时的注意事项

## 1. 不得把 `bi` 和 `LortImage` 混用

错误示例：

```text
读取屏幕到bi("big", 0, 0, 0, 0)
LortImage转灰度("big", "gray")
```

这里的 `big` 是 `bi` 对象，不能直接作为 LortImage 对象使用。

---

## 2. 不得自行修改返回格式

例如：

```text
模板找图bi
```

已经确认返回：

```text
x, y|匹配得分|最佳缩放比例
```

不能自行改成：

```text
x,y,score,scale
```

---

## 3. 不得混淆不同命令的得分规则

`模板找图bi` 的匹配得分与 `轮廓找图bi` 的得分含义不同。

特别是：

```text
模板找图bi
```

与：

```text
轮廓找图bi
```

不能因为都有“得分”字段，就认为得分大小规律相同。

---

## 4. 未找到的返回值必须按照命令定义处理

坐标类命令常见：

```text
-1, -1
```

模板找图则可能返回：

```text
-1, -1|0.000|0.0
```

不能把所有命令的失败返回值强行统一成一种格式。

---

## 5. 使用数组时必须初始化元素

例如：

```text
index[0] = "960, 540"
color[0] = "FF0000"

index[1] = "970, 540"
color[1] = "FF1010"
```

然后再传给：

```text
bi坐标找色(...)
```

---

## 6. 坐标找色和普通找色不是同一个概念

普通颜色查找：

```text
bi区域找色(...)
```

主要寻找某一种颜色。

坐标找色：

```text
bi坐标找色(...)
```

则使用中心点和偏移点的颜色关系判断目标。

不要因为两者都叫“找色”而混用。

---

## 7. `bi` 图像处理命令是否修改原图必须注意

例如：

```text
bi读取像素范围重设颜色值(...)
```

会把结果保存到新的 `bi`，原图不修改。

而：

```text
bi里排除中间区域(...)
```

直接修改原 `bi` 对象。

---

## 8. 图像资源可以提前载入

循环中频繁执行找图时，小图建议提前：

```text
读取图片到bi("small", "c:/楚河脚本/资源目录/目标图片.png")
```

然后重复使用：

```text
bi找图("big", "small", ...)
```

避免在循环中反复从磁盘读取模板图片。

---

## 9. 示例中的说明性注释必须遵守楚河脚本注释规则

本文档中的解释文字不代表楚河脚本语法。

实际脚本注释仍必须遵守：

* `//` 注释只能位于行首
* `/*` 和 `*/` 必须单独占行

不要把普通说明文字写到命令行末尾，当作楚河脚本注释。

---

## 10. 不得根据其他语言创造图色命令

楚河脚本中的：

```text
bi找图
模板找图bi
bi区域找色
bi坐标找色
轮廓找图bi
```

等命令均有自己的参数和返回规则。

即使 Java、Python、OpenCV 中存在类似功能，也不能据此推测楚河脚本存在其他未确认的命令或参数。
