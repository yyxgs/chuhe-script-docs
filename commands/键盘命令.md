# 楚河脚本键盘命令

本文档记录楚河脚本中已经确认的键盘相关命令。

生成楚河脚本时，命令名称、参数顺序和调用方式必须以本文档为准，不得根据其他编程语言自行推测。

---

## 1. 按下

### 语法

```text
按下按键名称
```

按下指定键，只执行键盘按下操作，不自动弹起。

### 示例

```text
按下a
等待(200)
弹起a
```

其他示例：

```text
按下enter
弹起enter
```

---

## 2. 弹起

### 语法

```text
弹起按键名称
```

弹起指定键。

### 示例

```text
按下a
等待(200)
弹起a
```

---

## 3. 按键

### 语法

```text
按键(键值)
```

```text
按键(键值, 按下毫秒数)
```

```text
按键(键值, 0, 0)
```

`按键`用于执行一次按键操作。

### 示例

```text
按键(65)
```

键值 `65` 对应大写字母 `A` 的 ASCII 值。

```text
按键(90)
```

键值 `90` 对应大写字母 `Z` 的 ASCII 值。

指定按下时间：

```text
按键(66, 200)
```

---

## 4. 按键的按下/弹起控制

第三参数可以用于控制按键状态。

```text
按键(65, 0, 0)
```

表示只执行按下。

```text
按键(65, 0, 1)
```

表示执行弹起。

## 5. 获取键盘监听键值

### 语法

```text
获取键盘监听键值()
```

获取当前键盘监听到的键值。

### 示例

```text
key = 获取键盘监听键值()
显示(key)
```

---

## 6. 设置键盘监听键值

### 语法

```text
设置键盘监听键值(键值)
```

设置键盘监听使用的键值。

### 示例

```text
设置键盘监听键值(0)
```

---

## 7. 获取键盘状态键值

### 语法

```text
获取键盘状态键值(键值)
```

根据指定键值获取该按键的状态。

官方教程中记录了以下状态值：

* `1`：按下并释放
* `0`：释放
* `-32767`：按下
* `32768`：按住

### 注意

官方教程中的示例代码与上述状态值说明存在数值不一致的情况：教程示例曾使用 `-32768` 判断“按住”。

因此，在没有进一步通过实际实现确认之前，**AI 不应自行修正或推测该状态值**。

## AI 生成注意事项

### 1. `按下` 和 `弹起` 是独立操作

例如：

```text
按下a
等待(200)
弹起a
```

不能因为其他编程语言通常使用一个函数完成按键操作，就自行改变楚河脚本语法。

### 2. `按键` 的键值必须明确

例如：

```text
按键(65)
```

使用的是键值，而不是：

```text
按键("A")
```

除非其他官方文档明确确认该写法有效。

### 3. 不要自行修改键盘状态值

`获取键盘状态键值()` 的教程资料存在状态值说明与示例不一致的问题。

在该问题被实际实现确认之前，应保留这一不确定性，不要让 AI 自行判断哪个数字才是正确值。

### 4. 英文逗号

参数之间必须使用英文逗号：

```text
按键(66, 200)
```

不要使用中文逗号：

```text
按键(66，200)
```

### 5. 不要把教程说明文字当成代码

教程中为了说明功能而写在代码后面的文字属于说明信息，不代表楚河脚本支持行尾注释。
