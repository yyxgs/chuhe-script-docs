# 楚河脚本坐标与转换命令

本文档记录已经确认的楚河脚本坐标、数据类型及数据转换相关命令。

---

## 1. x

### 命令介绍

从坐标字符串中提取 X 坐标。

例如：

```text
str = "100, 200"
```

使用：

```text
坐标x = x(str)
```

得到：

```text
坐标x = 100
```

### 语法

```text
x(坐标字符串)
```

### 示例

```text
图片路径 = "c:/楚河脚本/截图.png"

截图(0, 0, 1919, 1079, 图片路径)

结果 = 区域找色(图片路径, 100, 100, 300, 300, "C8C8C8")

x坐标 = x(结果)

显示(x坐标)
```

也可以直接用于其他命令：

```text
str = "100, 200"

坐标x = x(str)

鼠标左键点击(坐标x, 300)
```

## 4. 字符转数字

### 命令介绍

一般用于将字母转换为对应的 ASCII 数字。

例如 ASCII 码表中：

```text

```

```text

```

### 示例

```text
str = "a"

number = 字符转数字(str)

显示(number)
```

## 8. 坐标字符串分离

### 命令介绍

将字符串中的坐标分别提取到指定变量中。

### 语法

两坐标：

```text
坐标字符串分离(字符串, 变量名1, 变量名2)
```

四坐标：

```text
坐标字符串分离(字符串, 变量名1, 变量名2, 变量名3, 变量名4)
```

### 示例

```text
str = "100, 200, 300, 400"

坐标字符串分离(str, leftX, leftY, endX, endY)

println("leftX的值是: ", leftX, "，leftY的值是: ", leftY, "，endX的值是: ", endX, "，endY的值是: ", endY)
```

## 14. 坐标是否在指定区域范围内

### 命令介绍

判断一个坐标是否在指定的区域范围内。

### 语法

```text
坐标是否在指定区域范围内(x, y, 左上角x, 左上角y, 右下角x, 右下角y)
```

### 返回值

* `是`：坐标在指定区域范围内。
* `否`：坐标不在指定区域范围内。

### 示例

```text
x = 400
y = 400

result = 坐标是否在指定区域范围内(x, y, 300, 300, 800, 800)

如果 result 等于 是
    显示("在这个范围内")
    等待(1000)
否则
    显示("不在这个范围内")
    等待(1000)
如果完成
```

## 16. 扩散坐标范围

### 命令介绍

通过坐标字符串计算扩散后的矩形范围。

### 语法

```text
扩散坐标范围(坐标字符串, 左扩散值, 上扩散值, 右扩散值, 下扩散值, 输出左X, 输出左Y, 输出右X, 输出右Y)
```

### 参数

* `坐标字符串`：作为扩散基准的坐标。
* `左扩散值`：左方向扩散值。
* `上扩散值`：上方向扩散值。
* `右扩散值`：右方向扩散值。
* `下扩散值`：下方向扩散值。
* `输出左X`：输出计算后的左上角 X 坐标。
* `输出左Y`：输出计算后的左上角 Y 坐标。
* `输出右X`：输出计算后的右下角 X 坐标。
* `输出右Y`：输出计算后的右下角 Y 坐标。

### 示例

```text
point = "100, 200"

扩散坐标范围(point, -100, -80, 50, 60, leftX, leftY, rightX, rightY)

println(leftX)
println(leftY)
println(rightX)
println(rightY)
```

# AI 注意事项

1. `x()` 和 `y()` 用于从坐标字符串中分别取得 X、Y 坐标。
2. `xy()` 用于将两个数字坐标组合成坐标字符串。
3. `坐标字符串分离()` 可以将坐标字符串直接分离到指定变量。
4. `转换为坐标()` 则将坐标字符串转换为数组。
5. `坐标加法运算()` 和 `坐标减法运算()` 返回包含两个坐标的数组。
6. `坐标是否在指定区域范围内()` 返回 `是` 或 `否`。
7. `RGB转数组()` 用于处理十六进制 RGB 颜色字符串。
8. `字符转数字()` 和 `数字转字符()` 按 ASCII 字符与数字进行转换。
9. `转换为浮点数()` 和 `转换为整数()` 用于数据类型转换。
10. `扩散坐标范围()` 使用输出变量返回计算后的矩形坐标。
11. 生成代码时必须使用本文档已经确认的参数形式，不得根据其他编程语言自行推测参数。
