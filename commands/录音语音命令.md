# 楚河脚本：录音语音命令

本文件记录楚河脚本中的录音设备、语音识别以及声音检测相关命令。

---

# 一、语音识别

## 1. 录音设备列表名称

### 功能

枚举当前电脑上所有可用的录音设备（麦克风）。

返回一个字符串数组，数组中包含每个录音设备的名称。

常用于在 `语音识别开始()` 前确认设备名称。

### 语法

```text
list = 录音设备列表名称()
```

### 示例

```text
list = 录音设备列表名称()

i = 0
length = 获取数组长度(list)

循环 i 小于 length
	println("设备：", list[i])

	i = i + 1
循环完成
```

---

## 2. 语音识别初始化

### 功能

加载语音识别模型。

这是一个耗时操作，建议在程序启动时调用一次。

模型路径必须使用**绝对路径**。

### 语法

```text
语音识别初始化("模型路径")
```

### 示例

```text
path = "D:/ChuHe/models/vosk-model-small-cn-0.22"

语音识别初始化(path)

println("语音模型加载完毕，准备就绪")
```

---

## 3. 语音识别开始

### 功能

开启录音线程，开始进行语音识别。

录音设备使用关键词进行模糊匹配，并且区分大小写。

如果关键词为空字符串 `""`，则默认使用第一个可用的麦克风。

### 语法

```text
语音识别开始("设备关键词")
```

### 示例

```text
语音识别开始("Microphone")

println("开始监听，请说话...")
```

---

## 4. 语音识别停止

### 功能

停止当前录音线程并关闭麦克风。

不会卸载已经加载的语音模型。

停止后可以再次调用 `语音识别开始()`。

### 语法

```text
语音识别停止()
```

### 示例

```text
语音识别停止()
```

# 二、声音检测

## 8. 声音检测开始

### 功能

启动一个后台线程，持续监听指定录音设备的音量。

当音量超过指定阈值时，标记为检测到声音。

该命令不会阻塞主脚本，需要配合 `获取声音检测结果()` 使用。

### 参数

1. **设备名称关键词**

   * 模糊匹配
   * 区分大小写
   * 填写 `""` 时匹配第一个可用设备

2. **音量阈值**

   * 范围：`0~32767`
   * 超过此值才算检测到声音
   * 可以先使用 `获取声音检测音量()` 观察实际音量

3. **冷却时间**

   * 单位：毫秒
   * 两次触发之间的最小间隔
   * 用于防止同一个声音重复触发

4. **设备名称编码格式**

   * Windows 中文系统填写 `"GBK"`
   * 其他情况填写 `"UTF-8"`

### 语法

```text
声音检测开始("设备关键词", 阈值, 冷却ms, "编码格式")
```

### 示例

```text
声音检测开始("CABLE", 800, 500, "GBK")
```

---

## 9. 声音检测停止

### 功能

停止声音检测后台线程，并释放录音设备资源。

停止后，`获取声音检测结果()` 将不再更新。

### 语法

```text
声音检测停止()
```

### 示例

```text
声音检测停止()
```

---

## 10. 获取声音检测结果

### 功能

获取当前是否检测到声音。

返回：

* `1`：检测到声音
* `0`：没有检测到声音

取到 `1` 后会自动清空，因此不会重复返回同一次触发结果。

通常在循环中进行轮询。

### 语法

```text
result = 获取声音检测结果()
```

### 示例

```text
声音检测开始("CABLE", 800, 500, "GBK")

println("声音检测已启动")

循环 0 小于 1
	result = 获取声音检测结果()

	如果 result 等于 1
		println("检测到提示音！")
	如果完成

	等待(100)
循环完成

声音检测停止()
```

---

## 11. 获取声音检测音量

### 功能

获取当前实时音量值。

返回范围：

```text
0~32767
```

获取音量不会自动清空。

主要用于调试阶段观察实际音量大小，以确定合适的 `声音检测开始()` 阈值。

### 语法

```text
volume = 获取声音检测音量()
```

### 示例

```text
声音检测开始("CABLE", 0, 100, "GBK")

println("开始观察音量，请播放声音")

循环 0 小于 1
	volume = 获取声音检测音量()

	println("当前音量：", volume)

	等待(200)
循环完成

声音检测停止()
```

# AI 使用注意事项

1. `语音识别初始化()` 用于加载语音模型，模型路径必须使用绝对路径。
2. 语音模型加载属于耗时操作，通常在程序启动时初始化一次。
3. `语音识别开始()` 使用录音设备名称关键词进行模糊匹配，并区分大小写。
4. `语音识别开始("")` 表示使用第一个可用的录音设备。
5. `语音识别停止()` 只停止录音和识别线程，不卸载已经加载的模型。
6. 需要彻底释放语音识别资源时使用 `语音识别销毁()`。
7. `获取语音识别结果()` 和 `获取语音识别中间结果()` 是不同的命令，不要混用。
8. `声音检测开始()` 是独立的声音音量检测功能，不等同于语音文字识别。
9. `声音检测开始()` 在后台线程中运行，不会阻塞主脚本。
10. `获取声音检测结果()` 返回 `1` 后会自动清空该次触发结果。
11. `获取声音检测音量()` 不会自动清空，可以持续读取当前音量。
12. 可以先使用 `获取声音检测音量()` 观察实际音量，再确定 `声音检测开始()` 的阈值。
13. 设备名称涉及 Windows 中文系统时，应根据实际情况使用 `"GBK"` 编码。
14. 不要根据其他语音识别库自行推测楚河脚本的参数或命令。
