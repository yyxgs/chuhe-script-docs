# 楚河脚本文本文件命令

本文档记录楚河脚本中与文本文件、目录、文件操作以及大文本处理相关的命令。

## 一、读取文本

### 1. 读取文本

读取文本里的内容到一个数组中，编码默认是 UTF-8。

```text
读取文本(路径)
读取文本(路径, "UTF-8")
```

第2个参数为可选编码格式。

返回值为数组，每一行对应数组中的一个元素。

数组下标从 `0` 开始。

例如：

```text
path = "c:/楚河脚本/脚本目录/文本名.txt"
list = 读取文本(path)

i = 0
listLength = 获取数组长度(list)

循环 i 小于 listLength
	显示(list[i])
	等待(1000)

	i = i + 1
循环完成

显示("循环已结束")
```

---

## 二、读取文本并删除空行

### 2. 读取文本并删除空行

读取文本内容到数组，并自动删除空行。

```text
读取文本并删除空行(路径)
读取文本并删除空行(路径, "UTF-8")
```

第2个参数为可选编码格式，默认 UTF-8。

例如：

```text
文本列表 = 读取文本并删除空行("c:/楚河脚本/脚本目录/临时.txt")

长度 = 获取数组长度(文本列表)

i = 0
循环 i 小于 长度
	显示(文本列表[i])
	等待(1000)

	i = i + 1
循环完成
```

## 三、读取整个文本为字符串

### 3. 读取文本字符串

读取文本里的全部内容到一个字符串中，包括换行。

```text
读取文本字符串(路径)
读取文本字符串(路径, "UTF-8")
```

第2个参数为可选编码格式，默认 UTF-8。

例如：

```text
str = 读取文本字符串("c:/楚河脚本/脚本目录/临时.txt")

显示(str)
等待(1000)

str = 读取文本字符串("c:/楚河脚本/脚本目录/临时.txt", "GBK")

显示(str)
等待(1000)
```

## 四、写入文本

### 4. 写入文本

向文本文件中写入内容，默认 UTF-8。

```text
写入文本(路径, 内容)
```

例如：

```text
写入文本("d:/1.txt", "你好")
写入换行("d:/1.txt", 1)
```

---

## 五、写入字节

### 5. 写入字节

向文本文件中写入一个字节数字。

```text
写入字节(路径, 字节数字)
```

例如写入 `CRLF` 换行：

```text
写入字节("d:/1.txt", 13)
写入字节("d:/1.txt", 10)
```

## 六、写入字节字符串

### 6. 写入字节字符串

向文本文件中写入字节字符串。

```text
写入字节字符串(文本路径, 字节字符串)
```

字节字符串中的字节使用 `-` 分隔。

例如：

```text
path = "c:/下载/9.txt"

写入字节字符串(path, byteStr)
```

## 七、重写文本

### 7. 重写文本

向文本文件中写入内容，并删除原来的全部内容。

```text
重写文本(路径, 内容)
```

例如：

```text
重写文本("d:/1.txt", "你好")
```

执行后，原来的文本内容会被删除，只保留新写入的内容。

## 八、写入数组文本

### 8. 写入数组文本

将数组内容写入文本。

```text
写入数组文本(路径, list, "UTF-8", 换行的数量)
```

参数：

1. 文本路径
2. 数组
3. 编码格式，可使用 `UTF-8`、`GBK`
4. 每行写入后的换行数量

例如：

```text
list[0] = "苹果"
list[1] = "香蕉"
list[2] = "梨子"

写入数组文本("d:/1.txt", list, "UTF-8", 1)
```

## 十四、文本排序与去重

### 31. 读取坐标文本进行冒泡排序

读取保存坐标的文本，并根据指定数据进行冒泡排序。

```text
读取坐标文本进行冒泡排序(文本路径, 分隔字符串, 排序方式)
```

排序方式：

* `1`：从小到大
* `2`：从大到小

文本格式示例：

```text
56, 434---6***56
189, 434---4***189
390, 435---1***390
329, 434---2***329
261, 433---3***261
126, 435---5***126
```

其中：

* 每行前面保存坐标
* `---` 后面可以保存其他数据
* `***` 后面的数字用于冒泡排序

例如：

```text
path = "c:/下载/1.txt"

list = 读取坐标文本进行冒泡排序(path, "***", 1)

i = 0
length = 获取数组长度(list)

循环 i 小于 length
	显示(list[i])
	等待(500)

	i = i + 1
循环完成
```

---

### 32. 读取并删除文本重复行

读取文本并删除重复行。

```text
读取并删除文本重复行(文本路径, 分离字符串, 比较位置, 保留标识符)
```

其中：

* 第1、2个参数为固定参数
* 第3、4个参数为可选参数
* 第3个参数用于指定比较分隔字符串之前还是之后的内容
* 第4个参数用于指定存在某个标识符时保留该行

例如：

```text
path = "c:/下载/5.txt"

读取并删除文本重复行(path, "---", 1, "8")
```

# AI 使用注意事项

1. 本文档中的命令名称必须严格按照楚河脚本实际命令使用。
2. 不得因为其他语言存在类似功能而自行创造命令。
3. 文本行下标通常从 `0` 开始，尤其是 `读取文本指定行`、`删除文本指定行`、`大文本中读取指定行` 等命令。
4. `读取文本` 返回普通数组；`读取大文本` 使用大文本变量机制，两者不要混淆。
5. `读取资源目录临时文本变量` 和其线程安全版本使用的是楚河脚本资源目录。
6. 多线程同时读写资源目录临时文本时，应使用对应的线程安全命令。
7. 字节字符串通常使用 `-` 分隔，例如 `65-66-9-67-68`。
8. 教程中的 `//` 仅用于说明示例含义。楚河脚本正式代码的注释规则应以 `language/语言规则.md` 为准。
9. 如果某个命令的参数、返回值或特殊行为没有在官方资料中确认，不得自行推测。
